# 07. 採用 ― 構造化面接（入口を同じ物差しにする）

## 原則

1. **活躍する人しか採用しない。** 応募者を全員採用すれば目先の人手は埋まりますが、すぐ辞めれば意味がありません
2. **面接官の主観に頼らない。** 質問項目と評価基準を事前に決める
3. **面接官は自分に似た人を高く評価します。** このバイアスは複数人での審議でしか潰せません
4. **実態を隠さない。** 期待と現実のギャップ（リアリティ・ショック）を入社前に埋める

---

## 面接の設計

| 項目 | 内容 |
|---|---|
| 形式 | 構造化面接（全員に同じ質問を、同じ順で） |
| 面接官 | 1次：管理者＋1名／2次：EM＋管理者（**必ず複数人**） |
| 評価 | 8大項目 × 各2問、0〜3点で採点 |
| 決定 | **週1回の選考会議で複数人が議論して決める。** 面接官の単独判断で決めない |
| 記録 | 回答の**事実部分**をメモする（印象ではなく、いつ・何をしたか） |

### 聞き方は「過去の事実」だけ

意見や意欲を聞いても採用の精度は上がりません。**過去の行動を聞きます。**

- ❌ 「チームワークは大事だと思いますか」
- ⭕ 「**直近1年で**、同僚を助けた場面を1つ教えてください。**そのとき自分の仕事はどうなりましたか**」

深掘りは3段階で行います。

```
1. 状況：いつ、どこで、誰が関わっていましたか
2. 行動：あなたは具体的に何をしましたか（「チームで」ではなく「あなたが」）
3. 結果：その後どうなりましたか。振り返って何を変えますか
```

## 大項目別 質問集

### ① 理念の行動化
- 「前職で、**会社の方針と自分の考えが食い違った**ことはありますか。どうしましたか」
- 「あなたが看護で**絶対に譲れないこと**は何ですか。それを守るために何かを諦めた経験はありますか」

**見るもの**：譲れないものを持っているか。持っているだけでなく、**行動で守った事実**があるか。

### ② 察知と発信
- 「**誰も気づいていない段階で**『これはまずい』と感じた経験はありますか。何を見てそう思いましたか」
- 「上司に**言いにくいこと**を報告した経験を教えてください。どう伝えましたか」

**見るもの**：数値以外のサインを挙げられるか。**言いにくいことを言った事実**があるか。
「報告しました」だけでなく、**タイミングが早いか**を確認します。

### ③ 当事者責任
- 「**自分の担当ではないのに**、自分が引き受けた仕事はありますか。なぜ引き受けましたか」
- 「うまくいかなかった仕事について教えてください。**原因は何だったと思いますか**」

**見るもの**：失敗の原因を「環境・他人・制度」だけで説明していないか。
**自分の関与を1つでも挙げられるか**（＝他責思考のスクリーニング）。

### ④ 支援行動
- 「直近1年で、同僚を助けた場面を1つ。**そのとき自分の仕事はどうなりましたか**」
- 「利用者・患者さんが**言えていなかった困りごと**に気づいた経験はありますか」

### ⑤ 約束履行
- 「約束を守れなかった経験を教えてください。**そのとき何をしましたか**」
- 「複数の仕事が重なったとき、**何を落とさないようにしていますか**。具体的な工夫は」

**見るもの**：完璧さではなく、**守れないと分かった時点で連絡できるか**。

### ⑥ 誠実さ
- 「**自分のミス**について教えてください。誰に、いつ伝えましたか」
- 「**苦手なこと**は何ですか。それに対して何をしていますか」

**見るもの**：ミスを話せない人は、現場でも隠します。
**苦手を認めたうえで手を打っている人**を高く評価してください。器用さは見ません。

### ⑦ 学習と適応
- 「ここ1年で**新しく覚えたこと**は何ですか。きっかけは何でしたか」
- 「職場のやり方が変わったとき、どう対応しましたか」

**見るもの**：**指示される前に**動いた事実があるか。研修に「行かされた」話しか出てこないなら1点。

### ⑧ 信頼と求心力
- 「同僚から**どんなことで頼られますか**」
- 「前職の同僚は、あなたをどう説明すると思いますか」

**見るもの**：具体的なエピソードで答えられるか。抽象的な自己評価だけなら1点。

## 見送りライン（重要）

> **ボーダーラインの候補者は、後で必ず問題が出ます。
> スキルが高くても、違和感があれば見送ってください。**

以下は、他が高得点でも**見送り**とします。

| 条件 | 理由 |
|---|---|
| ⑥誠実さ が **1点以下** | 隠す人は、訪問看護では事故に直結します。単独訪問が前提の業態で、隠蔽は致命的です |
| ⑤約束履行 が **1点以下** | 利用者・家族との約束が守られない前提の運用は組めません |
| ③当事者責任 が **1点以下** | 失敗の原因をすべて他人・環境に帰す人は、教育コストが回収できません |
| 過去の退職理由が**すべて他責** | 同じことが自社でも起きます |
| **面接官の誰か1人が強い違和感を表明** | 理由が言語化できなくても見送り。多数決で押し切らないこと |

**技術・経験の不足は入社後に埋められます。上記は埋められません。**

## 入社前に必ず伝えること（リアリティ・ショック対策）

隠して採用した分は、必ず3ヶ月目に離職で返ってきます。**先に全部伝えてください。**

| 伝えること | 具体的に |
|---|---|
| 訪問件数の実態 | 「1〜2年目は月80〜85件が目安です。3年目以降は75件に下げ、その分**別の役割**をお願いします」 |
| 件数を下げる理由 | 「件数を減らして楽をしてもらうためではなく、**後輩の育成や連携に時間を使ってもらう**ためです」 |
| オンコールの実態 | 回数、手当、明けの扱い、実際の呼び出し頻度 |
| 記録の量 | 1日あたりの記録時間、いつ書くか、直行直帰の可否 |
| 単独訪問の孤独 | 「基本は1人で判断して1人で入ります。相談できる体制はこうなっています」 |
| 看取り | 年間何件くらいか、初回はどう支援するか |
| 給与の実態 | 手当込みの実額、賞与の変動幅、評価がどう反映されるか |
| 3ヶ月目が一番きついこと | 「多くの人が入社3ヶ月目に負荷が上がります。**そのタイミングで本部から必ず会いに行きます**」 |

> 最後の1行を伝えられることが、この制度を持っている会社の強みです。
> 「きついのは分かっている。だから先回りする仕組みがある」と言える組織は、
> 「うちはアットホームです」と言う組織より圧倒的に信用されます。

## 面接評価シート（採点の目安）

| 点 | 状態 |
|---|---|
| 3 | 具体的な事実で語れる。行動の主語が「私」。結果と振り返りまである |
| 2 | 事実で語れるが、深掘りすると曖昧になる部分がある |
| 1 | 一般論・意見・意欲で答える。事実が出てこない |
| 0 | 質問と噛み合わない、または懸念のある内容（他責・隠蔽の示唆） |

## 選考会議（週1回）

| 内容 |
|---|
| 面接官が**先に点数だけ**を出す（議論の前に。同調を防ぐため） |
| 点数が割れた項目について、**それぞれの根拠となった事実**を共有 |
| 見送りラインに触れていないか確認 |
| 「自分に似ているから高くつけていないか」を必ず1回問う |
| 決定（採用／見送り／保留＋追加面談） |
