# 10. 当たり前制度ゲートと、件数インセンティブ

> **標準は80件。75件は「下がる」のではなく「勝ち取る」ものです。**

この章が、件数ボーダーの運用ルールの中心です。他の章より先に読んでください。

---

## 1. 3つの数字の関係

| 数字 | 意味 |
|---|---|
| **80件** | **標準ライン。件数インセンティブの基準**。ここを超えた分にインセンティブがつく |
| **75件** | **当たり前制度をクリアした3年目以降の人だけ**が適用される負荷上限 |
| **70／65件** | G4・G5。75件適用中にNVA枠の成果が確認できた人が、さらに下がる |

```
              ┌──────────────────────────────────────┐
  3年目以降 →  │ 当たり前制度クリア？                 │
              └──────────────┬───────────────────────┘
                     クリア  │  未クリア
                   ┌────────┘└────────┐
                   ▼                   ▼
        75件 ＋ NVA枠 ＋ 役割手当     80件のまま
        （件数インセンティブ対象外）  （件数インセンティブ対象）
                   │
                   │ NVA枠の成果が2期連続で確認できた
                   ▼
              G4：70件 → G5：65件
```

### 言い方（現場に伝えるときの一文）

> 「75件は、当たり前ができている人にだけ渡す枠です。
> 件数を減らすかわりに、後輩と連携先に時間を使ってもらう。
> 当たり前ができていない人に、後輩は預けられません。」

**これが制度全体を一番よく説明します。** 75件を「配慮」や「時短」として説明した瞬間に、
当たり前ができていない人から「自分も下げてほしい」という話になり、制度が崩れます。

---

## 2. なぜ「当たり前制度クリア」を条件にするのか

75件に下げた人がやるのは、**新人同行・記録レビュー・困難事例の相談役・連携先訪問**です。
つまり「**他人に見本を見せる仕事**」に時間を使うということです。

| 当たり前ができていない人に75件を渡すと | 起きること |
|---|---|
| 記録が遅れる人が記録レビューをする | 拠点全体の記録品質が下がる |
| 報告が遅い人が新人に同行する | 新人が「報告は遅れてもいい」と学習する |
| 約束を守れない人が連携先を回る | 会社の信用が落ちる |
| 挨拶・時間・身だしなみが崩れている人が見本になる | 当たり前制度そのものが形骸化する |

**当たり前制度は、75件の前提条件であると同時に、75件の中身そのものです。**
だからゲートを置きます。

---

## 3. ゲートの判定ルール

### 判定の対象と条件

| | 内容 |
|---|---|
| **対象** | 入社3年目以降（G3以上） |
| **クリア基準** | **当たり前制度の全項目が「できている」。部分クリアは不可** |
| **判定者** | 管理者が一次判定 → エリアマネージャーが二次確認 → **統括責任者が承認** |
| **判定時期** | 四半期評価と同じタイミング（年4回） |
| **有効期間** | **6ヶ月**。半期ごとに再判定する |
| **未クリアの場合** | 80件のまま。**何が満たせていないかを本人に書面で伝え、次の判定日を明示する** |

> **なぜ満点方式（部分クリア不可）なのか。**
> 当たり前は「8割できている」では当たり前ではないからです。
> 一方で、**満点方式にできる程度に項目数を絞ってください**（10〜12項目が上限）。
> 項目が多すぎると誰もクリアできず、ゲートが機能しません。

### 失効（75件適用を解除して80件に戻す）

以下は、有効期間の途中でも即座に解除します。

| 失効事由 | 理由 |
|---|---|
| 事故・ミス・ヒヤリハットの**隠蔽** | 見本になれない。単独訪問が前提の業態で致命的 |
| **不適正な算定**を意図的に行った | 会社の存続に関わる |
| ハラスメント行為が確認された | 同上 |
| 法令・加算要件の期限管理の**重大な漏れ** | 同上 |
| 当たり前制度の項目が**2ヶ月連続で崩れた** | 見本として成立していない |
| **NVA枠の成果が2期連続で確認できない** | 75件の対価が返ってきていない |

**解除は罰ではなく、原状復帰です。** 80件に戻し、役割手当を止め、件数インセンティブの対象に戻します。
再判定は次の四半期から受けられます。**「一度落ちたら二度と上がれない」にはしないでください。**

---

## 3-2. 当たり前制度と人事評価は、別物として扱う

当たり前制度の項目と、評価の24項目は**内容が一部重なります**（記録の当日完了、隠さない報告など）。
ここで運用を間違えると、**同じ事実で何度も不利益を与える制度**になります。

| | 当たり前制度 | 人事評価 |
|---|---|---|
| 何を決めるか | **75件を適用するかどうか（ゲート）** | 昇給・賞与・昇格（処遇） |
| 判定 | 全項目○／×（部分クリアなし） | 0〜3点の4段階 |
| 結果 | 75件 or 80件のまま | スコア → 処遇 |

**ルール：未クリアであること自体を、評価点から追加で引かない。**

- ⭕ 記録が遅れたという**事実**を、S3-3で1点として採点する
- ⭕ 同じ事実により、当たり前制度の「記録の当日完了」を×とする
- ❌ **「当たり前制度が未クリアだったから」という理由で、評価点をさらに下げる**

未クリアの結果は「**80件のまま**」だけです。等級も基本給も変わりません。
ここを守らないと、制度が「罰の重ね掛け」に見えます。

## 4. 当たり前制度チェック項目（雛形）

> **⚠ ここは貴社ですでに運用している「当たり前制度」の項目に差し替えてください。**
> 下記は、差し替えるまでの雛形です。項目を足すのではなく、**貴社の項目に置き換える**のが正しい使い方です。

| No | 項目 | 判定の目安（できている＝○） |
|---|---|---|
| 1 | 挨拶を自分から、相手に届く声でする | 利用者・家族・同僚・連携先。例外なく |
| 2 | 訪問の開始・終了時刻を守る。遅れるときは**事前に**連絡する | 事後報告は「できていない」 |
| 3 | 記録を当日中に完了させる | 月の記録遅延が0件 |
| 4 | 報告・連絡・相談を、聞かれる前に自分からする | 管理者が「聞きに行かないと分からない」状態でない |
| 5 | 提出物の期限を守る。守れないときは事前に申告する | 督促を受けた回数が0 |
| 6 | 申し送りを、次の人が困らない形で残す | 受け手からの差し戻しが0 |
| 7 | 身だしなみ・社用車・持ち物を清潔に保つ | 抜き打ちで見て問題がない |
| 8 | ミス・ヒヤリハットを隠さず当日中に報告する | 隠蔽ゼロ。**報告数が多いことは減点にしない** |
| 9 | 会議・研修に遅れない。無断欠席しない | 遅刻・無断欠席が0 |
| 10 | 決まったルール（手順・算定・個人情報の扱い）を守る | 逸脱の指摘が0 |
| 11 | 不在の人の話を悪く語らない | 管理者・360度で懸念が出ていない |
| 12 | 使ったもの・借りたものを元に戻す | 事務所・車内・物品管理 |

判定シートは [sheets/当たり前制度チェックシート.csv](sheets/当たり前制度チェックシート.csv) を使ってください。

## 5. 件数インセンティブの設計

### 基本

| 状態 | 件数インセンティブ | 役割手当（NVA手当） |
|---|---|---|
| **80件ライン（G1・G2・ゲート未クリアのG3以上）** | **80件を超えた分に支給** | なし |
| **75件適用者（G3以上・ゲートクリア）** | **原則なし** | **あり**（下記） |
| G4（70件）・G5（65件） | なし | あり（役割に応じて増額） |
| 管理者・エリアマネージャー | なし | 役職手当に含む |

### 75件適用者の役割手当をどう決めるか

ここを間違えると、**誰も75件に手を挙げません。**

```
役割手当の下限 ＝ 件数インセンティブ 5件分相当 × 1.0 以上

  ※ 80件基準の人が85件回して得るインセンティブと、
     75件でNVA枠をやり切った人の役割手当が、
     手取りでおおむね同等以上になるように置く
```

**理由：** 75件適用者は件数インセンティブを取れなくなります。
ここで手取りが下がる設計にすると、「当たり前をクリアするほど損をする」という
制度としてあり得ない状態になります。**必ず同等以上にしてください。**

役割手当は四半期のNVA枠評価に連動させ、次のように扱います。

| NVA枠テーマの達成 | 役割手当 |
|---|---|
| 達成（2点以上） | 満額を継続 |
| 一部達成（1点） | 満額を継続。ただし次期のテーマを組み直す |
| 未達（0点）が2期連続 | **75件適用を解除し80件に戻す**（＝手当停止・インセンティブ対象へ復帰） |

### 75件適用者が80件を超えてしまった場合

| 状況 | 扱い |
|---|---|
| 緊急対応・欠員カバーでやむを得ず超過した | **その超過分には件数インセンティブを支給してよい**。断る動機を作らないため |
| 2ヶ月連続で超過した | **75件適用を一旦解除し80件に戻す**。本人の問題ではなく<br>**管理者の配置設計の問題**として、管理者評価でマイナスにする |
| 本人の希望で件数を積んでいる | 面談。75件適用を続けるか、80件に戻すかを本人と決める |

> **「75件のまま80件以上回して、手当もインセンティブも取る」状態を作らないでください。**
> これを1人でも許すと、制度は3ヶ月で崩壊します。

## 6. G4・G5へ下げる条件（70件・65件）

年次だけでは下げません。**成果が確認できた人から順に下げます。**

| 段階 | 条件 |
|---|---|
| **80件 → 75件** | ① 3年目以降 ② **当たり前制度クリア** ③ NVA枠の使途契約 |
| **75件 → 70件（G4）** | ① 75件適用が**2期連続で維持** ② NVA枠の成果が2期連続で「達成」<br>③ **行動スコア 75点以上（100点換算）が2期連続** ④ 統括責任者の承認 |
| **70件 → 65件（G5）** | ① G4が2期連続で維持 ② 拠点運営の一部を実際に担っている<br>（シフト設計・教育計画・管理者代行のいずれか） ③ 統括責任者の承認 |

**下げるたびに、返してもらう役割が増える。** これがこの制度の一本の筋です。

---

## 7. 統括責任者の承認ポイント（このゲートで見るもの）

| 承認するもの | 見るべき点 |
|---|---|
| 当たり前制度クリアの承認 | 管理者の判定が**甘くなっていないか**。拠点間で判定の厳しさが揃っているか |
| 75件適用の開始 | **NVA枠の使途契約が具体的か**（「後輩の指導」ではなく「新人Aの同行を月8時間」） |
| 役割手当の額 | **件数インセンティブと同等以上**になっているか |
| 75件適用の解除 | 解除が**本人の罰**になっていないか。管理者の設計問題として扱えているか |
| G4・G5への降下 | 成果が2期分の**事実で示されているか**。年次だけで上げていないか |

> **拠点間で当たり前制度の判定が揃っていないことが、この制度の最大のリスクです。**
> 「A拠点は甘い」が広がると、当たり前制度そのものの権威が消えます。
> 四半期のキャリブレーション会議で、**当たり前制度の判定も必ず突き合わせてください。**
