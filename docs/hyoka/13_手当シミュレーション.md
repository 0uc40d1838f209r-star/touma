# 13. 役割手当と件数インセンティブのシミュレーション

> **この章の数字は、貴社の実額を入れて計算し直してください。**
> ここに置いてあるのは**計算の型**と、**判断のしかた**です。

制度が動くかどうかは、この1点で決まります。

> **75件を選んだ人の手取りが、80件で回している人より下がらないか。**

下がる設計にした瞬間、当たり前制度をクリアした人ほど損をします。誰も手を挙げません。

---

## 1. 計算の型

### 前提として置く数字（自社の実額に差し替えてください）

| 記号 | 意味 | 仮置き |
|---|---|---|
| `P` | 訪問1件あたりの粗利（売上 − 直接原価） | 仮に **7,000円** |
| `I` | 件数インセンティブの単価（80件を超えた1件あたり） | 仮に **2,000円／件** |
| `N` | 80件ラインの人が実際に回している平均件数 | 仮に **85件** |

### 比較する2人

```
Xさん：80件ライン。実績85件。
       件数インセンティブ ＝ (85 − 80) × I ＝ 5 × 2,000 ＝ 10,000円／月

Yさん：75件適用。実績75件。NVA枠 月8.75時間。
       件数インセンティブ ＝ 0円
       役割手当 ＝ ？
```

### 役割手当の下限

```
役割手当 ≧ (N − 80) × I
        ＝ 5件分のインセンティブ相当
        ＝ 10,000円／月   ← これが下限
```

**推奨は下限の1.2〜1.5倍（12,000〜15,000円／月）です。**
下限ちょうどだと「同じなら件数を回したほうが気楽」となり、手が挙がりません。
**少しだけ得**にしておくのが、制度が動く条件です。

---

## 2. 会社側の損得（ここを統括責任者が確認します）

### 表面上のコスト

```
Yさんが75件になることによる粗利の減少
  ＝ (80 − 75) × P × 12ヶ月
  ＝ 5 × 7,000 × 12 ＝ 420,000円／年

役割手当の追加コスト
  ＝ 12,000 × 12 ＝ 144,000円／年
  （ただし件数インセンティブ 10,000×12 ＝ 120,000円/年 が不要になるため、
    実質の追加は 24,000円／年）

1人あたりの年間コスト ≒ 420,000 + 24,000 ＝ 約444,000円
```

### 回収の見込み

| 回収の道 | 効き方 |
|---|---|
| **離職の抑制** | 看護師1名の離職コストを **150万円** と置くと、<br>**3人が75件になっても、離職1名を防げば1.0倍で回収**（444,000×3 ≒ 133万円） |
| **新人の立ち上がり短縮** | NVA枠の同行で独り立ちが1ヶ月早まると、1名あたり数十万円の効果 |
| **単価の向上** | 記録・計画の品質向上 → 加算取得率が1〜2ポイント上がるだけで拠点単位では数十万円 |
| **新規紹介の増加** | 連携先訪問が実行されることで、月1件の新規増加でも年間で大きい |

> **結論の出し方はこうです。**
> 「75件を◯名に適用する。年間コストは約◯◯万円。
> これに対し、**入社1年以内の離職を年◯名減らせれば回収できる。**
> 現在の入社1年以内離職は年◯名なので、△名減で足りる。」
>
> **この一文が言えれば、経営として決められます。**

## 3. シミュレーション表（30名規模の例）

| 区分 | 人数 | 1人あたり件数 | 月間総件数 | 件数インセンティブ | 役割手当 |
|---|---|---|---|---|---|
| G1 新人 | 4名 | 60（立ち上げ中） | 240 | 0 | 0 |
| G2 一人前 | 8名 | 85 | 680 | 5件×8名 ＝ 80,000円 | 0 |
| G3（80件のまま・ゲート未クリア） | 5名 | 84 | 420 | 4件×5名 ＝ 40,000円 | 0 |
| **G3（75件適用）** | **6名** | **75** | **450** | **0** | **12,000×6 ＝ 72,000円** |
| **G4（70件）** | **3名** | **70** | **210** | **0** | **20,000×3 ＝ 60,000円** |
| G5（65件） | 1名 | 65 | 65 | 0 | 28,000円 |
| 管理者 | 4名 | 45 | 180 | 0 | 役職手当に含む |
| **合計** | **31名** | — | **2,245件** | **120,000円** | **160,000円** |

### 導入前との比較（仮）

| | 導入前（全員80件ライン） | 導入後 |
|---|---|---|
| 月間総件数 | 2,300件 | 2,245件（**−55件**） |
| 月間の粗利差 | — | −385,000円 |
| インセンティブ＋手当 | 200,000円 | 280,000円（**+80,000円**） |
| **月間コスト増** | — | **約465,000円** |
| **年間コスト増** | — | **約558万円** |

### この558万円をどう見るか

```
離職コスト 150万円／名 とすると
  → 年間の離職を 3.7名 減らせれば回収

現在の年間離職が 8名 なら、4.3名まで下げれば回収できる
（離職率が 26% → 14% になる水準）
```

> **この計算を、自社の実数でやってください。**
> 「回収できる」と言えるなら進める。言えないなら、
> **適用人数を絞る**（まずG3の希望者3名から）という選択があります。
> 全員一斉にやる必要はありません。

---

## 4. 段階導入という選択肢

年間558万円が重い場合、次の順で絞れます。

| 段階 | 対象 | 年間コスト（上の例） |
|---|---|---|
| **第1段階** | 各拠点1名ずつ（4名）の75件適用から | 約180万円 |
| 第2段階 | ゲートクリア者全員（G3の希望者） | 約380万円 |
| 第3段階 | G4・G5への降下を開始 | 約558万円 |

**第1段階で半年回し、離職率と新人の立ち上がり期間を測ってから第2段階へ。**
これが最も安全な進め方です。

> ただし、**第1段階の4名の選び方には注意してください。**
> 「一番できる人」を選ぶと、その人の件数が減った分を他の人が被り、
> 拠点全体の負荷が上がって逆効果になります。
> **選ぶのは「当たり前をクリアしていて、かつ後輩を見るのが向いている人」**です。

## 5. 統括責任者のチェックポイント

```
□ P（1件あたり粗利）と I（インセンティブ単価）の実額を入れたか
□ 役割手当は「5件分のインセンティブ相当 × 1.2〜1.5」になっているか
□ 75件適用者の手取り年額を、80件ラインの人と実際に並べて計算したか
□ 年間コスト増を「離職◯名分」に換算したか
□ 現在の年間離職数と比べて、回収可能と言えるか
□ 言えないなら、第1段階（各拠点1名）に絞ったか
□ 第1段階の対象者を「できる人」ではなく「見本になれる人」で選んだか
```
