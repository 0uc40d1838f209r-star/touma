# 06. 運用マニュアル

制度は「作ること」ではなく「回し続けること」で価値が出ます。
ここでは **4拠点以上・スタッフ30名超** を前提に、誰が・いつ・何分でやるかまで決めます。

---

## 1. 年間カレンダー

| 頻度 | 誰が | やること | 所要 |
|---|---|---|---|
| **毎週** | 管理者 | 週次モニタ：件数進捗／オンコール回数／パルス（晴れ曇り雨）を並べて見る。曇り2回連続・件数ボーダー超過ペースは面談予約 | 10分 |
| **毎月** | 管理者 | 全スタッフと1on1（後述の型） | 15分 × 人数 |
| **毎月** | 管理者 | 判断ログ 1件以上を記録・共有 | 20分 |
| **毎月** | EM | エリアモニタ：拠点別の件数**ばらつき**、離職・パルス・記録期限・加算取得率 | 60分 |
| **毎月** | 本部／採用担当 | 入社3ヶ月・6ヶ月・12ヶ月の該当者を拠点訪問（営業時間中） | 1名30分 |
| **四半期** | 本人 | 自己評価（24項目）＋NVA枠テーマの振り返り | 30分 |
| **四半期** | 管理者 | 一次評価＋評価面談 | 30分 × 人数 |
| **四半期** | EM | 二次評価 | 拠点あたり60分 |
| **四半期** | EM＋管理者全員 | **キャリブレーション会議**（後述） | 90分 |
| **半期** | 経営 | 処遇反映（昇給・賞与）、等級と件数ボーダーの見直し | — |
| **年1回** | 全員 | 360度フィードバック（匿名） | 15分 |
| **年1回** | EM | 評価者訓練（管理者向け・事例3本で採点を揃える） | 半日 |
| **年1回** | 経営 | 昇格判定 | — |

> **管理者の負担は月あたり「1on1×人数 ＋ 週次10分×4 ＋ 判断ログ20分」です。**
> スタッフ8名の拠点なら月およそ3時間。これは管理者の件数ボーダー（40〜50件）に織り込み済みです。
> **時間を渡さずに評価だけ増やすと、必ず形骸化します。**

## 2. 月次1on1の型（15分・管理者）

固定の4問だけです。時間をかけないことが継続の条件です。

| 時間 | 問い | 見ているもの |
|---|---|---|
| 3分 | 「今月、**一番しんどかったのはどの訪問／どの日**でしたか」 | 負荷の実態（件数では見えない重症度・家族対応） |
| 4分 | 「**うまくいったこと**を1つ教えてください。何がよかったと思いますか」 | 理念の行動化、成功の言語化 |
| 4分 | 「**NVA枠のテーマ**、今月はどれくらい進みましたか」（G3以上） | 件数を下げた分の返し方 |
| 4分 | 「**私（管理者）に、してほしいことはありますか**」 | 約束履行の起点。ここで出た依頼は次回冒頭で必ず結果を返す |

### 「雨」が出た人への対応（重要）

パルスで「雨」が出た人、または曇りが2回続いた人には**追加面談**を入れます。
このとき、聞き方に原則があります。

- ❌ 不満を全部吐き出させる → ネガティブが増幅して、辞める決心が固まるだけです
- ⭕ **良い点をあえて聞く** … 「管理者（先輩）のいいところはどこですか」
- ⭕ **関係を前向きに戻す** … 「管理者があなたのことを褒めていましたよ」（事実に基づく範囲で）
- ⭕ **どちらか一方の味方をしない。「二人の間の関係」を扱う**

管理者本人が原因になっている可能性があるため、**「雨」が2回続いた場合は本部／EMが直接面談**します。
新人は直属の上司には相談できません。これは本人の問題ではなく**構造**です。

## 3. 四半期評価の流れ

```
[本人] 自己評価（24項目 + NVA枠振り返り）
   ↓
[管理者] 一次評価 … 各項目に「点数 + 根拠となる事実1行」を必ず書く
   ↓
[EM] 二次評価 … 一次評価の根拠が事実になっているかを見る（点数の上書きはこの段階ではしない）
   ↓
[キャリブレーション会議] 拠点間の甘辛を調整 → 確定
   ↓
[管理者] 評価面談 … 点数ではなく「事実」と「次の1つ」を伝える
```

### 一次評価のルール

1. **根拠のない点数は無効**。「2点」だけの記入は差し戻し
2. **3点をつけるなら、必ず具体的な事実を1つ書く**（「一つ上の階層の動きをした」証拠）
3. **0点をつけるなら、その期のうちに本人に伝えてあったこと**が条件（評価面談で初めて聞かされる0点は禁止）

### 評価面談の型（30分）

| 時間 | 内容 |
|---|---|
| 5分 | 自己評価と一次評価の**差が大きい項目だけ**を確認（全項目を読み上げない） |
| 10分 | **事実を伝える**。「〇月の△△さんの件で、あなたが××したこと」を具体的に |
| 5分 | 点数と処遇への反映を説明。**理由を必ず言う**（M6-1） |
| 10分 | **次の四半期のテーマを1つだけ決める**。NVA枠の使途も合わせて決める |

> **改善点を3つ以上伝えない**でください。人は1つしか変えられません。

---

## 4. キャリブレーション会議（30名超では必須）

**目的：管理者の甘辛を消すこと。** 30名を超えると「A拠点は評価が辛い」が離職理由になります。

### 手順（90分・EM主催・全管理者参加）

| 時間 | 内容 |
|---|---|
| 10分 | 拠点別の平均点・分布を並べて表示 |
| 20分 | **拠点平均が全社平均から ±0.3点以上ズレている拠点**は、根拠を再提示 |
| 40分 | **各拠点から「3点をつけた人」と「1点以下をつけた人」を1名ずつ挙げ、事実を読み上げる。** 他の管理者が「自分の拠点なら何点か」を言う |
| 15分 | 調整（点数の変更はここでのみ可能。変更理由を記録） |
| 5分 | 次期の重点項目を確認 |

### 分布の目安（強制はしない）

| 区分 | 目安 | 意味 |
|---|---|---|
| S（65点以上／72点） | 10% | 一つ上の階層の動きをしている |
| A（55〜64点） | 25% | 期待を上回る |
| B（40〜54点） | 50% | 期待どおり（**ここが標準。全員がここでも組織は健全**） |
| C（39点以下） | 15% | 支援が必要 |

> **相対分布を強制すると、制度は必ず嫌われます。** 目安から大きく外れた拠点に
> 「なぜそうなったのか」を説明させるための参照値として使ってください。
> 本当に全員が良い拠点は存在します。その場合は**根拠の事実が濃いか**だけを確認します。

## 5. 処遇への反映

### スコアの合成

| 階層 | 行動スコア | 成果スコア |
|---|---|---|
| スタッフ（G1〜G5） | **70%** | 30% |
| 管理者 | **50%** | 50% |
| エリアマネージャー | 40% | **60%** |

```
総合スコア ＝ 行動スコア（72点満点を100点換算）× 重み
            ＋ 成果スコア（100点満点）× 重み
```

### スタッフの成果スコア（30%の内訳）

| 領域 | 指標 | 配点 |
|---|---|---|
| 負荷の適正 | **件数ボーダー遵守**（90〜100%が満点。**超過は減点しないが加点もしない**） | 30 |
| NVA枠 | 設定テーマの達成（G3以上。G1〜G2は件数と学習に配分） | 30 |
| 質 | 記録期限遵守率、インシデント（**報告数ではなく重大事故の有無**） | 25 |
| 貢献 | 代行・応援の実績、勉強会の実施 | 15 |

> **件数の「超過」を加点しない設計にしてください。**
> 超過を加点した瞬間に、75件ボーダーは絵に描いた餅になります。
> 一方で超過を**減点**すると、緊急対応を断る動機になります。だから **加点も減点もしない**。
> 超過は[管理者の]成果スコアでマイナスに扱います（[03](03_管理者層_評価項目.md)）。

### 賞与係数（例）

| 総合スコア | 係数 |
|---|---|
| 90以上 | 1.30 |
| 80〜89 | 1.15 |
| 70〜79 | 1.05 |
| 55〜69 | 1.00（標準） |
| 45〜54 | 0.90 |
| 44以下 | 0.80 ＋ **改善計画とセット** |

### 昇給（半期）

| 総合スコア | 昇給 |
|---|---|
| 2期連続 80以上 | 昇給＋等級見直しの候補 |
| 70〜79 | 標準昇給 |
| 55〜69 | 標準昇給 |
| 54以下 | 据え置き＋支援計画（**据え置きの理由と、次に何をすれば上がるかを必ず文書で渡す**） |

### 欠格事由（点数に関わらず処遇を保留）

以下は総合スコアが高くても、昇給・賞与の増額・昇格を保留します。

- ⑥誠実さ（S6-2 / M6-2）で、**事故やミスの隠蔽**が確認された
- **不適正な算定**を意図的に行った
- ハラスメント行為が確認された
- ⑤約束履行で、**法令・加算要件の期限管理の重大な漏れ**が確認された

---

## 6. 異議申し立て

- 評価面談から**2週間以内**に、本人からEMへ申し立てできる
- EMは、一次評価の**根拠となった事実**を本人と一緒に確認する（点数の議論はしない）
- 事実が確認できない項目は、**評価を「無効」として分母から外す**（点数を上げるのではなく無効にする）

> この仕組みがあるだけで、管理者は根拠を書くようになります。
> 実際に使われる回数はほとんどゼロで構いません。

---

## 7. 運用を軽くするための原則

| 原則 | 理由 |
|---|---|
| **評価は四半期。ただし1on1は毎月** | 半年に1回だと事実を思い出せず、印象評価になる |
| **1on1は15分、フォーマット固定** | 長くすると続かない。続かない制度は無いのと同じ |
| **紙／表計算で始める** | システム化は運用が回ってから。仕組みから入ると中身が薄くなる |
| **管理者の評価負担を件数ボーダーに織り込む** | 時間を渡さずに仕事を増やさない |
| **項目は増やさない** | 追加したくなったら、既存項目のどれかを削る |
