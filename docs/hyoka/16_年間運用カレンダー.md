# 16. 年間運用カレンダー

「四半期に」「毎月」では予定は押さえられません。**月を決めます。**
下記は **4月始まり** の例です。自社の期に合わせてずらしてください。

## 四半期の詳細スケジュール（7月＝Q1評価の例）

| 日程 | 誰が | やること |
|---|---|---|
| **6/25 まで** | 本人 | 自己評価（24項目）＋ NVA枠テーマの振り返りを提出 |
| **6/30 まで** | 管理者 | 当たり前制度の一次判定を提出（G3以上） |
| **7/5 まで** | 管理者 | 一次評価を提出（**各項目に根拠の事実1行が必須**） |
| **7/10 まで** | EM | 二次評価・当たり前制度の二次確認 |
| **7/15** | 全管理者＋EM＋統括責任者 | **キャリブレーション会議（90分）**<br>・拠点別の評価分布<br>・**当たり前制度クリア率の拠点差**<br>・3点／1点以下をつけた事例の読み合わせ |
| **7/18 まで** | 統括責任者 | 承認（当たり前制度クリア／75件適用の開始・解除） |
| **7/25 まで** | 管理者 | 評価面談（30分／人）。**次期のテーマを1つだけ決める** |
| **7/31 まで** | 管理者 | 次期のNVA枠使途契約を締結（G3以上） |
| **8/8 まで** | 本人 | 異議申し立て期限（面談から2週間） |

> **提出物の期限を、制度側が守ってください。**
> ⑤約束履行を評価する制度が、自分の期限を守らないと信用されません。

## 半期でやること（10月・4月）

| やること | 誰が |
|---|---|
| **処遇反映**（昇給・賞与係数の確定） | 統括責任者 → 経営 |
| **当たり前制度の再判定**（有効期間6ヶ月の更新） | 管理者 → EM → 統括責任者 |
| **役割手当の額の見直し** | 統括責任者（[13_手当シミュレーション](13_手当シミュレーション.md) を再計算） |
| **G4・G5への降下の判定** | 統括責任者 |
| **件数ボーダーの妥当性確認**（5つの指標） | 経営 |

### 半期に確認する5つの指標

```
□ 件数を下げた等級で、NVA枠の成果が実際に出ているか
□ 拠点収支は悪化していないか（悪化なら単価か稼働で取り返せているか）
□ 離職率は改善しているか（特に入社1年以内）
□ 件数の「ばらつき」は縮んでいるか（平均ではなく分散）
□ 記録期限遵守率は落ちていないか（＝NVA枠が休憩に化けていないか）
```

**2つ以上が悪化していたら、次の降下は止めて原因を潰します。**

## 年1回だけやること

| 時期 | やること | 誰が |
|---|---|---|
| **3月** | **評価者訓練**（半日・事例3本） | EM主催・全管理者 |
| **3月** | 評価項目の見直し（**増やすのではなく減らす**） | EM＋管理者 |
| **2月** | 昇格判定 | 昇格会議（3名以上・推薦者以外を含む） |
| **10月** | 360度フィードバック（匿名） | 全員 |
| **4月** | 等級・件数ボーダー・当たり前制度項目の見直し | 統括責任者 |

> **新任管理者には、着任1ヶ月以内に評価者訓練を行ってください。**
> 3月の年次訓練を待つと、その管理者の拠点が最初の四半期で必ず甘辛の外れ値になります。

## 制度が止まりやすい時期（先回りしておく）

| 時期 | 起きること | 手当て |
|---|---|---|
| **導入3ヶ月目** | 1on1が「今月も特にないです」で終わり始める | 4つめの質問（私にしてほしいこと）を必ず聞く。**前回の依頼への回答から始める** |
| **年度末（2〜3月）** | 現場が忙しく、1on1と判断ログが飛ぶ | **飛ばしてよい月を作らない。**代わりに1on1を10分に短縮してよい |
| **初回の処遇反映（10月）** | 「思ったより上がらない」という反応が出る | 標準がB＝1.00であることを、**評価面談で必ず先に説明する** |
| **管理者の交代時** | 判断ログも当たり前制度の判定基準も引き継がれない | **最低3ヶ月の重複期間**と、判断ログの引き継ぎを必須にする |
| **2年目以降** | 項目が形骸化し、全員2点になる | 年1回、**項目を減らす**。追加したくなったら既存のどれかを削る |
