# 訪問看護 人材評価・運用パッケージ

「1人あたり月間訪問件数のボーダーを 3年目以降75件、以降は年次ごとに逓減させていく」
という経営判断を、**評価と運用で成立させる**ためのドキュメント一式です。

## この制度が答えようとしている問い

件数ボーダーを下げるだけなら誰でもできます。難しいのはその先です。

> 訪問を10件減らした人が、**空いた時間で組織に何を返したのか**を、
> 誰がどう見て、どう処遇に反映するのか。

ここが定義されていないと、件数の引き下げは単なる収益悪化になります。
逆にここが定義できれば、件数を下げるほど「育成・定着・単価・連携」が強くなり、
**少ない件数で同じ利益が出る組織**に変わります。

本パッケージは、いただいた8つの大項目（求める人物像）を、
その「返し方」を測るための**小項目・評価基準・運用手順**に落としたものです。

## 8つの大項目（全階層共通）

| # | 大項目（求める人物像） | 短縮名 | 階層で変わること |
|---|---|---|---|
| 1 | 理念に共感し、それを日々の行動に落とし込める人 | 理念の行動化 | 自分がやる → 拠点でやれる状態にする → 会社の基準にする |
| 2 | 現場の変化やリスクに気づき、自分から報告・相談できる人 | 察知と発信 | 利用者と自分 → 拠点とスタッフ → 拠点間と会社 |
| 3 | 誰かに任せきりにせず、自分の担当範囲に責任を持てる人 | 当事者責任 | 担当利用者 → 拠点の結果 → エリアの結果と構造 |
| 4 | 困っている同僚や利用者に自然と手を差し伸べられる人 | 支援行動 | 目の前の人 → 拠点の偏り → 拠点間の平準化 |
| 5 | 大事なことを忘れない、約束を守れる人 | 約束履行 | 利用者との約束 → スタッフ・法令との約束 → 管理者・経営との約束 |
| 6 | 不器用でも誠実に取り組む姿勢がある人 | 誠実さ | 隠さない → 都合の悪いことも伝える → 数字を操作しない |
| 7 | 変化を前向きに受け止め、学び続けられる人 | 学習と適応 | 自分が学ぶ → 前例のない事例を判断する → 先を読んで備える |
| 8 | 周囲から信頼され、自然と人が集まってくる人 | 信頼と求心力 | 利用者・同僚 → スタッフ・地域 → 管理者・社外 |

**翻訳のルールはひとつだけです。**
同じ大項目が、階層が上がるごとに
「**自分がやる → やれる状態をつくる → やれる仕組みと人を育てる**」に変わります。

## 評価の基本設計（4段階）

| 点 | 呼称 | 意味 |
|---|---|---|
| 3 | 役割を超えている | 一つ上の階層の動きをしている。事実で示せる |
| 2 | 期待どおり | その等級として問題なく機能している（**ここが標準**） |
| 1 | 部分的 | できる時とできない時がある／人や場面に依存する |
| 0 | 未達 | 期待行動が確認できない、または反する行動がある |

- **5段階にしない**理由：中央（3）に逃げる評価者が必ず出るため。偶数段階で立場を決めさせます。
- **各小項目に「確認方法（エビデンス）」を必ず付けています。** 印象で点をつけさせないためです。
- 満点は 24小項目 × 3点 = **72点**。100点換算して行動スコアとします。

## 使い道（4つとも同じ物差しで動かします）

1. **育成・面談のフィードバック** … 月次1on1、四半期評価
2. **昇給・賞与への反映** … 行動スコア＋成果スコアの合成（[06](06_運用マニュアル.md)）
3. **昇格の判断** … スタッフ→管理者→EM（[05](05_昇格の壁.md)）
4. **採用の見極め基準** … 構造化面接（[07](07_採用_構造化面接.md)）

入口（採用）と入社後（評価・昇格・処遇）が**同じ8項目**で貫かれていることが、
この制度の一番の狙いです。面接で見た人物像と、現場で評価される人物像がズレると、
どちらも信用されなくなります。

## 前提の規模

- 4拠点以上／スタッフ30名超
- したがって**評価者間のばらつき対策（キャリブレーション）は必須**です。
  30名を超えた時点で、「管理者の甘辛」が離職理由になります。詳細は [06](06_運用マニュアル.md)。

## まず何から始めるか

0. **統括責任者にはまず [00_統括責任者向け_使い方.md](00_統括責任者向け_使い方.md) を渡してください。**
1. **[08_導入ロードマップ.md](08_導入ロードマップ.md) の Month 0 だけを先にやってください。**
   件数分布・離職率・離職コスト試算・退職者の時系列分析の4つ。
   これが揃うと「75件」は経営判断として通ります。揃わないと思いつきに見えます。
2. 次に [01_設計思想と件数ボーダー.md](01_設計思想と件数ボーダー.md) の件数ボーダー表を自社の数値に置き換える。
3. 評価項目（02〜04）は、**管理者と一緒に1〜2項目書き換えてから**配ってください。
   自分たちで作った項目が混ざっているだけで、運用の定着率が変わります。
