# 05. 昇格の壁 ― 延長線上にない力を、どう見極めるか

## 前提：昇格は「点数の高い順」ではありません

評価点が高い＝次の階層で活躍できる、ではありません。
むしろ**プレイヤーとして優秀だった人ほど、次の階層で詰まります**。
自分の成功体験が、そのまま部下への押し付けになるからです。

昇格判定は、**現階層の評価点（足切り）＋ 次階層の壁を越えられるかの見極め** の2段構えで行います。

```
昇格の条件 ＝ ①現階層の行動スコアが2期連続 75点以上（＝おおむね全項目2点以上）
            ＋ ②「壁」の項目で、事実に基づく確認が取れている
            ＋ ③欠格事由がない（⑥誠実さ・⑤約束履行に1点以下がない）
```

---

## 壁① スタッフ → 管理者

スタッフとして優秀な人は、①〜⑧のうち「自分がやりきる」系の項目で高得点を取ります。
しかし管理者に必要なのは、**自分がやることではなく、矛盾を引き受けて決めること**です。

### 越えるべき2つの壁

#### 壁1-A：矛盾を、自分の責任で決められるか

管理者は毎日、正解のない衝突を処理します。

| 衝突 | スタッフの反応 | 管理者に必要な反応 |
|---|---|---|
| 利用者優先 ⇔ 職員保護 | 「かわいそうだから続けるべき」 | どちらを優先し、**犠牲にした側にどうフォローするか**まで決める |
| 24h維持 ⇔ 労基法遵守 | 「人が足りないのが悪い」 | 今の人員でどこまでやるかの線を引き、**引けない部分を上に上げる** |
| 売上維持 ⇔ 適正算定 | 「上が決めること」 | **自分の名前で止める／取ると決める** |

**見極めの質問（昇格面接で使用）**

> 「利用者さんのご家族から、あるスタッフに対して強い言い方をされる状況が続いています。
> そのスタッフは『大丈夫です』と言っています。担当を替えると利用者は不安定になり、
> 売上も落ちます。あなたならどうしますか。**そして、その判断で損をする側に何をしますか。**」

- **0〜1点**：「本人に確認します」「上に相談します」で止まる（＝判断していない）
- **2点**：判断はできるが、犠牲にした側へのフォローが薄い
- **3点**：判断・理由・フォロー・1ヶ月後の再評価まで設計できている

#### 壁1-B：数字になる前の異常を察知できるか

「数字は正常なのに現場は崩壊寸前」を見抜けるかどうかです。

**見極めの質問**

> 「これまでに、**誰も気づいていない段階で**『この人（この利用者／この家族）は危ないかもしれない』
> と感じたことはありますか。何を見てそう思いましたか。その後どうなりましたか。」

- **0〜1点**：数値（バイタル、件数、残業時間）しか挙げられない
- **2点**：非数値のサイン（口数、記録の書きぶり、家族の沈黙）を1〜2個挙げられる
- **3点**：サインを挙げ、**自分から動き、実際に何かを防いだ事実**がある

### 管理者候補の育て方（壁を越えさせる）

**研修では育ちません。** 短期の管理者研修で身につくのは、会議進行・数字管理・面談の形式だけです。
必要なのは、**修羅場・葛藤・失敗・板挟み・孤独・責任・理不尽を、支援つきで通過させること**です。

| 育成手段 | 具体 |
|---|---|
| 判断ログの読み合わせ | 現管理者の判断ログを月1本、候補者と読む。「自分ならどう決めたか」を先に言わせてから答えを見る |
| 権限の一部委譲 | 新規依頼の受け／断りの判断を、月2件だけ候補者に任せる（管理者は事後レビューのみ） |
| 板挟みの同席 | 苦情対応・家族面談・医師との交渉に同席させる。**代わりに話さない** |
| 失敗の許容枠 | 「この範囲なら失敗してよい」を明示する。失敗の後始末は管理者・EMが黙って引き受ける |

## 壁② 管理者 → エリアマネージャー

**プレイヤーと管理者の間より、管理者とEMの間のほうが断絶は大きい**です。
管理者としてチームの数字を上げ続けていても、ここから先に進めない人がいます。
逆に管理者としての成果が突出していなくても、EMに上がる人がいます。求められるものが違うからです。

管理者になるまでに身につく力（＝現場をやりきる過程で自然に身につく）：

1. **ウェットなコミュニケーション力** … 関係性で人を動かす
2. **やり切る力** … ボトルネックを自分で外す

EMに必要だが**延長線上にない**力：

3. **蓋然性を語る力**
4. **人の個性を使い分ける力**

### 壁2-A：蓋然性を語る力

「経営の方向性はどうかと思う」「利用者のためにはこうすべきだ」と言える人は組織にたくさんいます。
言っていることは正しい。筋も通っている。**でも「じゃあどうするか」が薄い。**

蓋然性を語る力とは、論理的に説明する力ではありません。
**先を決め、文脈をつくり、なぜそこに行くのかの確からしさをつくる力**です。

| レベル | 状態 |
|---|---|
| 0〜1点 | 感想は言える。対案がない。「べき論」で止まる |
| 2点 | 対案は出せる。ただし反対者の想定・コスト・現場の業務変化まで詰めていない |
| 3点 | **会議に出る前に、誰が反対するかを読み、全方位にアイデアを当ててブラッシュアップしてから臨んでいる。** 費用感・現場の業務変化・移行期の痛みまで語れる |

**見極めの課題（昇格審査で実施）**

> 「エリア全体で、3年目以降の件数ボーダーを75件に下げます。
> 半年後に収支を落とさずに移行するための計画を、A4一枚で出してください。
> **誰が反対するか、その人に何を言うかまで書いてください。**」

見るのは提案の巧拙ではなく、**反対者の想定と、移行期の痛みへの手当てがあるか**です。

### 壁2-B：人の個性を使い分ける力

管理者の範囲なら、似たタイプを集めればなんとかなります。合わなければ配置を変えればいい。
数人単位なら、自分が頑張ればカバーもできてしまう。

しかしエリアは、**性格も強みもバラバラな管理者を、そのまま束ねる**仕事です。
同じタイプだけでは複数拠点は回りません。

管理者で止まる人の共通点は、**部下を自分の劣化模倣品として見る**ことです。
自分のやり方を押し付け、同じ水準を期待し、できないと失望する。
悪意はありません。**むしろ熱心だからこそそうなります。**

| レベル | 状態 |
|---|---|
| 0〜1点 | 「A管理者はもっとこうすべき」と、自分のやり方を基準に語る |
| 2点 | 個性の違いは理解している。ただし役割設計に反映できていない |
| 3点 | **管理者ごとに違う役割・違う支援の仕方を設計し、説明できる。** 自分と違うやり方の成果を認めている |

**見極めの質問**

> 「今いる管理者を1人ずつ挙げて、**その人の一番の強みと、その強みをどこで使っているか**を教えてください。
> また、あなたのやり方とは違うが結果が出ている管理者はいますか。何が違いますか。」

## ボスとリーダーの違い（昇格判定の共通の物差し）

管理者以上の昇格判定では、迷ったときにこの物差しを使ってください。

| ボス | リーダー |
|---|---|
| 「私」と言う | 「**我々**」と言う |
| 失敗の責任を負わせる | **黙って失敗を処理する** |
| やり方を胸に秘める | **やり方を教える** |
| 仕事を苦役に変える | 仕事をゲームに変える |
| 「やれ」と言う | 「**やろう**」と言う |

数字を出していても左側の人は、階層が上がるほど組織を壊します。
**特に「失敗の責任を負わせる」が常態化している人は、昇格を見送ってください。**

---

## 昇格判定の手続き（4拠点以上・30名超の場合）

| ステップ | 実施者 | 内容 |
|---|---|---|
| 1. 推薦 | 直属の上長 | 現階層の評価2期分＋推薦理由（事実ベース） |
| 2. 壁の確認 | EM／経営 | 上記の質問・課題を実施。**複数人で評価** |
| 3. 審議 | 昇格会議（3名以上） | 推薦者以外が必ず入る。面接官が自分に似た人を高く評価するバイアスを潰すため |
| 4. 判定 | 経営 | 見送りの場合、**何が足りないかを本人に必ず伝え、次の育成計画とセットにする** |

> **見送りの伝え方が制度の信用を決めます。**
> 「今回は見送り」だけを伝えると、その人は辞めます。
> **「何が足りず、どうすれば越えられ、次はいつ判定するか」**を必ずセットで渡してください。
