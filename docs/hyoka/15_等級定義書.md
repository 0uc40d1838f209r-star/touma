# 15. 等級定義書

評価項目は「どう働くか」を定めますが、**等級は「何をどこまで決めてよいか」を定めます。**
ここが曖昧なまま「権限内の判断を自分で決めているか」（M3-2）を評価すると、
**評価される側は何が権限内か分からず、評価する側も基準を持てません。**

各等級について、次の5つを定義します。

| 項目 | 意味 |
|---|---|
| **役割** | この等級の人が組織に対して負っているもの |
| **決めてよいこと（権限）** | 上に確認せず自分で決めてよい範囲 |
| **上に上げること** | 必ず上長の判断を仰ぐ範囲 |
| **件数ボーダー** | 適用される月間訪問件数の上限 |
| **次に上がる条件** | 昇格・降下の条件 |

---

## G1｜新人（〜12ヶ月）

| | |
|---|---|
| **役割** | **自分の訪問を、安全に成立させる。** 組織への貢献はまだ求めない |
| **決めてよいこと** | ・指示書・計画書の範囲内での、その日のケアの進め方<br>・訪問時間の微調整（利用者都合の±15分程度） |
| **上に上げること** | ・**判断に迷ったことすべて**（迷ったら上げるのが正しい等級）<br>・利用者の状態変化、家族からの要望、時間の大幅な変更<br>・自分の体調不良（**これを上げられないと次に進めません**） |
| **件数ボーダー** | 40件から段階的に80件へ。目安：1〜3ヶ月40〜55件／4〜6ヶ月55〜70件／7〜12ヶ月70〜80件 |
| **次に上がる条件** | ・単独訪問が全担当で成立している<br>・**⑥誠実さ・⑤約束履行 が2点以上**（隠さない・約束を守る）<br>・オンコールの一次対応ができる |

> **G1で最も見るのは「言えるか」です。**
> 分からないと言える、体調が悪いと言える、ミスをしたと言える。
> ここができない人は、経験を積むほど危険になります。

---

## G2｜一人前（13〜24ヶ月）

| | |
|---|---|
| **役割** | **自分の担当を、督促なしで完結させる。** ここが標準ラインです |
| **決めてよいこと** | ・自分の担当利用者に関する、日々のケアの判断<br>・訪問順・ルートの組み立て<br>・家族への説明（指示書の範囲内）<br>・緊急時の一次対応（受診勧奨まで） |
| **上に上げること** | ・指示書の変更が必要な状態変化<br>・家族・利用者からの苦情、ハラスメント性のある言動<br>・担当変更が必要と感じたとき<br>・**自分の負荷が上限に近いとき（S2-2）** |
| **件数ボーダー** | **80件**（件数インセンティブの基準） |
| **次に上がる条件** | ・**当たり前制度をクリア**（→75件を選べる）<br>・③当事者責任 が全項目2点以上<br>・後輩の質問に答えられる |

> **G2は「一番件数を回す等級」です。** ここがキャリアのピークになるよう設計しています。
> G3以降で件数を下げるための余力を、この2年で作ります。

---

## G3｜中堅（3年目〜）

| | |
|---|---|
| **役割** | **自分の担当に加えて、他人が仕事をしやすい状態をつくる。**<br>ここから「見本を見せる仕事」が始まります |
| **決めてよいこと** | ・G2の範囲すべて<br>・**新人の同行内容と進め方**（何を見せ、何をやらせるか）<br>・自分の担当における記録・計画書の書き方の指導<br>・困難事例での、他スタッフへの助言 |
| **上に上げること** | ・新人の独り立ち可否の**最終判断**（意見は出す。決めるのは管理者）<br>・新規依頼を受けるかどうか<br>・他スタッフの負荷が限界に見えるとき（**本人が言わなくても上げる**） |
| **件数ボーダー** | **75件**（当たり前制度クリア時）／未クリアは **80件** |
| **NVA枠** | 月8〜10時間。使途は四半期ごとに契約 |
| **次に上がる条件** | ・75件適用が**2期連続で維持**<br>・NVA枠の成果が2期連続で「達成」<br>・**行動スコア75点以上が2期連続**<br>・統括責任者の承認 |

---

## G4｜リーダー（4年目〜）

| | |
|---|---|
| **役割** | **チームの一部を預かる。** 管理者の判断を、現場側から支える |
| **決めてよいこと** | ・G3の範囲すべて<br>・**新規依頼の一次判断**（受ける／断るの意見を、根拠つきで出す）<br>・チーム内の訪問の振り分け・代行の手配<br>・新人の教育計画（月単位）<br>・連携先訪問の計画と実行 |
| **上に上げること** | ・新規依頼の**最終判断**（決めるのは管理者）<br>・スタッフの処遇・評価に関わること<br>・拠点全体の体制に関わること |
| **件数ボーダー** | **70件** |
| **NVA枠** | 月17〜20時間 |
| **次に上がる条件** | ・G4が2期連続で維持<br>・**拠点運営の一部を実際に担っている**（シフト設計・教育計画・管理者代行のいずれか）<br>・統括責任者の承認 |

> **G4は「管理者候補の入口」です。**
> ここで新規依頼の一次判断を任せ、**事後レビューだけにする**のが管理者育成の要です。
> 事前に管理者が確認してしまうと、判断の訓練になりません。

---

## G5｜主任／サブ管理者（5年目〜）

| | |
|---|---|
| **役割** | **管理者の不在時に、拠点を止めない。** 管理者と同じものを見る |
| **決めてよいこと** | ・G4の範囲すべて<br>・**シフトの原案作成**<br>・拠点の教育計画（四半期単位）<br>・管理者不在時の日常判断<br>・スタッフからの相談の一次受け |
| **上に上げること** | ・人事・処遇に関わること<br>・利用者との契約に関わること<br>・法令・算定の判断<br>・**管理者不在時でも、矛盾が衝突する判断は必ず管理者に連絡** |
| **件数ボーダー** | **65件** |
| **NVA枠** | 月26〜30時間 |
| **次に上がる条件** | [05_昇格の壁.md](05_昇格の壁.md) の**壁①**（矛盾を自分の責任で決められるか／数字になる前の異常を察知できるか）を越えること |

## 管理者

| | |
|---|---|
| **役割** | **拠点の結果を背負う。矛盾を調整する。** ルールの適用者ではない |
| **決めてよいこと** | ・**新規依頼の受け／断りの最終判断**<br>・担当の変更、シフトの確定<br>・スタッフの評価の一次判定、当たり前制度の一次判定<br>・拠点内の運用ルールの決定<br>・**「利用者優先 ⇔ 職員保護」「24h維持 ⇔ 労基」「売上 ⇔ 適正算定」の日々の調整**<br>・一定額までの拠点経費 |
| **上に上げること** | ・人員の増減、採用の要否<br>・ハラスメント事案・事故・行政指摘の**初動と同時に**<br>・**自分の権限では決められない矛盾**（法令に触れる可能性がある判断など）<br>・拠点の収支が計画から大きく外れる見込み |
| **件数ボーダー** | **40〜50件**（判断する時間を確保するため）<br>3ヶ月連続で50件超なら、**人員計画の問題としてEMが引き取る** |
| **次に上がる条件** | [05_昇格の壁.md](05_昇格の壁.md) の**壁②**（蓋然性を語る力／人の個性を使い分ける力）を越えること |

> **管理者の権限で最も重要なのは「断れること」です。**
> 新規依頼を断る権限を管理者に渡していない組織では、件数ボーダーは必ず崩れます。

## エリアマネージャー

| | |
|---|---|
| **役割** | **会社の文脈をつくり、進める。管理者を育てる。拠点間の差を消す。**<br>管理者の延長線上ではなく、役割の次元が変わります |
| **決めてよいこと** | ・拠点間の人員・応援の配分<br>・評価の二次判定、当たり前制度の二次確認<br>・拠点ごとに**違うやり方を認めること**<br>・エリア内の制度・運用ルールの改定提案と実行<br>・管理者の育成計画、次期候補の指名 |
| **上に上げること** | ・拠点の新設・統廃合<br>・等級・賃金制度の変更<br>・**当たり前制度クリアと75件適用の承認**（統括責任者へ）<br>・重大な事故・行政処分に関わる事案 |
| **件数ボーダー** | **0〜20件**（緊急バックアップのみ） |
| **求められること** | ・**蓋然性を語る力**（先を決め、文脈をつくり、確からしさをつくる）<br>・**人の個性を使い分ける力**（管理者を自分のコピーにしない）<br>・ウェットなコミュニケーション力／やり切る力 |

## 標準滞留年数と、その扱い

| 等級 | 標準滞留 | 注意 |
|---|---|---|
| G1 | 1年 | 短縮可（経験者採用など）。**短縮しても⑥誠実さ・⑤約束履行の確認は省かない** |
| G2 | 1年 | — |
| G3 | 1年以上 | **年次では上がりません。**75件を2期維持＋NVA成果が条件 |
| G4 | 1年以上 | 同上 |
| G5 | — | 管理者への昇格は壁①の通過が条件。**空きポストの有無とは切り離して判定する** |

> **「ポストが空いたから昇格」は、この制度では認めません。**
> 空きが出てから候補を探す組織は、必ず「管理者っぽい人」を昇格させることになります。
> **各拠点に常に1名の候補者を明示しておく**のは、EMの成果指標に入っています。
