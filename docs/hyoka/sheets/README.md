## 記入の鉄則

1. **点数だけの記入は無効。** 「根拠となる事実」欄が空欄の項目は差し戻す
2. **3点をつけるなら、一つ上の階層の動きをした事実を1つ書く**
3. **0点をつけるなら、その期のうちに本人へ伝えてあったこと**が条件
4. 週次モニタは**数字の右端に「気づいたこと」欄がある**。ここが本体です
