# 17. 規程整備チェックリスト

> **この章は法的助言ではありません。**
> 社会保険労務士・顧問弁護士に相談する際の**論点リスト**として使ってください。
> 実際の手続きと判断は、必ず専門家に確認してください。

制度設計が正しくても、**規程が追いついていないと導入できません。**
特に今回は **役割手当を新設し、条件によって停止する** ため、賃金に関わる変更が発生します。

---

## 1. 変更が必要になりうる規程

| 規程 | 何が変わるか | 手続きの目安 |
|---|---|---|
| **賃金規程** | **役割手当の新設**（支給要件・金額・停止条件） | 変更 → 労基署へ届出 |
| **賃金規程** | 件数インセンティブの支給条件の明確化（75件適用者の扱い） | 同上 |
| **就業規則** | 等級制度・評価制度の記載（すでにあれば改定） | 変更 → 届出 |
| **人事評価規程**（なければ新設） | 評価の時期・方法・異議申し立て手続き | 就業規則の一部として届出 |
| **等級規程**（なければ新設） | G1〜G5・管理者・EM の定義と昇格降格の条件 | 同上 |

> 常時10人以上の事業場では、就業規則の変更に**労働者代表の意見書**と**労基署への届出**が必要です。
> 4拠点ある場合、**事業場ごとの手続きが必要か**を必ず確認してください。

---

## 2. 役割手当の設計で、規程に書いておくべきこと

**ここが一番の論点です。** 役割手当は「一度払ったら下げられない」ものにしないでください。

| 書くこと | なぜ |
|---|---|
| **支給の目的** | 「訪問件数を抑えた分、教育・連携・品質管理の役割を担うことに対する対価」<br>→ **役割に対する対価**であることを明記する |
| **支給の要件** | ①当たり前制度のクリア ②75件（またはそれ以下）の適用 ③NVA枠の使途契約の締結 |
| **金額** | 適用ボーダーごとに定める（75件／70件／65件） |
| **支給期間** | **6ヶ月**。再判定により更新 |
| **不支給・停止の要件** | ・当たり前制度の再判定で未クリアとなったとき<br>・失効事由に該当したとき<br>・NVA枠の成果が2期連続で未達のとき<br>・件数が2ヶ月連続で80件を超えたとき |
| **停止時の扱い** | **停止と同時に、件数インセンティブの対象に復帰する**ことを明記 |

> **「役割に対する対価であり、その役割を担わなくなれば支給しない」**という構造を、
> 制度の最初から規程に書いておくことが重要です。
> あとから停止条件を追加するほうが、はるかに難しくなります。

### 確認すべき論点（社労士へ）

```
□ 役割手当の停止は、不利益変更にあたるか
   → 支給要件が規程に明記され、要件を満たさなくなったことによる停止であれば
     通常は問題になりにくいが、必ず確認する

□ 役割手当は、割増賃金の算定基礎に含まれるか
   → 家族手当・通勤手当・住宅手当など法定の除外賃金に該当しない手当は
     原則として算定基礎に含まれる。実務上の影響を確認する

□ 役割手当は、平均賃金・賞与・退職金の算定にどう影響するか

□ 件数インセンティブと役割手当の併給を制限することは可能か
   → 支給要件で切り分けられているかを確認する

□ 75件適用者が緊急対応で超過した分にインセンティブを支給する運用は、
   規程上どう書けば整合するか
```

## 3. 評価制度で、規程に書いておくべきこと

| 書くこと | なぜ |
|---|---|
| 評価の**時期と回数** | 四半期評価・半期の処遇反映 |
| 評価の**方法** | 自己評価 → 一次評価 → 二次評価 → 調整 → 面談 |
| 評価者 | 一次＝管理者／二次＝EM／承認＝統括責任者 |
| **異議申し立ての手続き** | 面談から2週間以内・申立先・確認する内容（点数ではなく事実） |
| 評価結果の**処遇への反映方法** | 昇給・賞与係数への反映の考え方 |
| **欠格事由** | 隠蔽・不適正算定・ハラスメント・重大な期限漏れ |

### 確認すべき論点（社労士へ）

```
□ 評価結果を賞与に反映する場合、賞与規程との整合は取れているか
□ 「据え置き」となる場合の説明義務・記録の残し方
□ 異議申し立ての手続きを規程に置くことの効果
□ 欠格事由による処遇保留の根拠を、どこに置くか
```

## 4. 労働時間まわりで確認すべきこと

件数ボーダーは**労働時間の上限ではありません。** ここを混同すると危険です。

| 論点 | 確認すること |
|---|---|
| **件数を下げても労働時間が下がらない場合** | NVA枠の活動が労働時間内に収まる設計になっているか。<br>**「訪問が減った分、勉強会は勤務時間外で」は成立しません** |
| **NVA枠の活動の労働時間性** | 同行・記録レビュー・連携先訪問はすべて**労働時間**です。<br>移動時間の扱いも含めて確認する |
| **オンコール** | 待機時間の労働時間性、手当、明けの勤務の扱い |
| **直行直帰** | 事業場外みなし労働時間制を使っている場合、<br>訪問件数の管理と整合するか |
| **記録の作成時間** | 自宅での記録作成が常態化していないか。<br>**記録遅延を評価する以上、記録の時間を勤務時間内に確保する必要があります** |

> **「記録の当日完了」を評価項目に入れるなら、記録を書く時間を勤務時間内に用意してください。**
> 用意せずに評価だけすると、サービス残業を評価で促していることになります。

## 5. 個人情報・記録まわり

| 論点 | 確認すること |
|---|---|
| **記録の抜き取りレビュー**（S1-2） | 他スタッフの担当利用者の記録を、G3以上が閲覧する運用になる。<br>アクセス権限の設計と、記録システム上の権限設定を確認 |
| **パルスサーベイ** | 収集する情報の範囲、保管期間、閲覧できる人の範囲を明示する。<br>**「評価には使わない」ことを本人に伝え、実際に使わない** |
| **360度フィードバック** | 匿名性の担保。**誰が書いたか特定できる形で管理者に渡さない** |
| **判断ログ** | 利用者・家族・スタッフの個人情報を含む。保管場所と閲覧範囲を決める |

## 6. 導入前チェックリスト

```
【規程】
□ 賃金規程に役割手当の条項を追加した（支給目的・要件・金額・期間・停止条件）
□ 停止と同時にインセンティブ対象へ復帰することを明記した
□ 評価制度の時期・方法・評価者・異議申し立てを規程に置いた
□ 等級定義（G1〜EM）を規程に置いた
□ 労働者代表の意見を聴取した
□ 労基署へ届け出た（事業場ごとの要否を確認した）

【労働時間】
□ NVA枠の活動が勤務時間内に収まる設計になっている
□ 記録を書く時間が勤務時間内に確保されている
□ オンコールの待機・出動・明けの扱いを確認した

【情報】
□ 記録レビューのためのアクセス権限を設計した
□ パルスサーベイの利用目的・保管・閲覧範囲を本人に説明した
□ 360度の匿名性を担保する運用を決めた

【説明】
□ 変更内容を全社説明会で説明した（[11_説明会スクリプトとFAQ](11_説明会スクリプトとFAQ.md)）
□ 規程の変更点を書面で周知した
□ 質問窓口を明示した
```

## 7. よくある落とし穴

| 落とし穴 | 結果 |
|---|---|
| **役割手当を「業績手当」として先に払い始める** | 支給要件が曖昧なまま既得権化し、あとから停止できなくなる |
| **規程を変えずに運用だけ先に始める** | 手当の停止時にトラブルになる。**規程が先です** |
| **「記録の当日完了」を評価しながら、記録時間を用意しない** | サービス残業を評価で促すことになる |
| **パルスサーベイを評価に使う** | 二度と本当のことを書かなくなる。制度の中で最も価値のあるデータが死ぬ |
| **当たり前制度の未クリアを人事評価の減点にも使う** | **二重の不利益**になる。未クリアは「75件を適用しない」だけに留める |

> **最後の1点は特に注意してください。**
> 当たり前制度のクリア／未クリアは、**75件適用の可否を決めるゲート**であって、
> 人事評価の点数そのものではありません。
> 同じ事実で、ゲートでも減点し、評価でも減点し、賞与でも減点する——
> これをやると制度が「罰の重ね掛け」に見えます。
