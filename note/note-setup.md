# note をゼロから始めて、最初の記事を出すまで

**所要：初回だけ90分ほど。2本目からは30分です。**

> note の画面のボタン名や配置は変わることがあります。ここに書いた名前と少し違っていても、
> **やることは同じ**なので、近い意味のボタンを探してください。

---

## 第1部　アカウントを作る（20分）

### 1. 登録する

1. [note.com](https://note.com) を開いて「会員登録」
2. メールアドレス、Google、X、Apple のどれかで登録
   - **会社の発信なので、個人のプライベート用アカウントとは分けてください**
3. 届いたメールから認証を済ませる

### 2. クリエイター名と note ID を決める

| 項目 | 入れるもの | 注意 |
| --- | --- | --- |
| クリエイター名 | `元管理者Ns` | あとから変更できます |
| note ID | `moto_kanrisha_ns` など | **あとから変更できません。慎重に** |

note ID は URL になります（`note.com/あなたのID`）。
名刺や求人票に載せることになるので、**短くて読めるもの**にしてください。

### 3. プロフィールを設定する

「設定」→「アカウント設定」から。

**プロフィール画像**
ロゴ（`note/assets/logo.jpg`）を使ってください。
ただし丸く切り抜かれるので、**顔のイラスト部分が中心に来るようにトリミング**してください。ロゴ全体を入れると小さくて読めません。

**ヘッダー画像**
ロゴ全体をそのまま使えます（横長なので相性がいい）。

**プロフィール文**（そのままコピーできます）

```
訪問看護ステーションで人事をしています。
24歳のとき、駅のホームでかかってきた電話一本で管理者になりました。
訪問看護も、管理者も、はじめてでした。

自分がやってきた人事の失敗だけを書いています。
うまくいった話は書きません。
```

**リンク**
**採用ページか応募フォームの URL を必ず設定してください。**
投稿を読んだ人が最初に押すのがここです。ここが空だと、興味を持った人の行き先がありません。

**SNS リンク**
X・Instagram のアカウントを登録しておく。相互に行き来できるようにします。

## 第2部　最初の記事＝自己紹介を出す（40分）

**1本目は連載ではなく、自己紹介記事です。** これをプロフィールに固定します。

### 4. 貼り付け用のテキストを作る

```bash
python3 note/make_note_text.py note/drafts/profile.md
```

`note/note-paste/` に2つできます。

- `profile.txt` ── **記号を抜いた本文。そのまま貼れます**
- `profile-整形メモ.txt` ── 貼ったあとに直す箇所のリスト

### 5. 記事を書く画面を開く

1. 画面右上の「**投稿**」
2. 「**テキスト**」を選ぶ

> 「つぶやき」「画像」ではありません。**必ず「テキスト」**です。

### 6. 見出し画像を入れる

いちばん上の「画像を追加」から、`note/instagram/out/profile/note-header.png` をアップロード。

> **1280×670 の画像を使ってください。**
> Instagram 用のカルーセル画像（1080×1350）は縦長なので、note では上下が切れて文字が読めなくなります。

### 7. タイトルと本文を入れる

1. **タイトル欄**に、整形メモの1行目をコピー
   ```
   【自己紹介】24歳で管理者になって、今は人を採る側にいます
   ```
2. **本文欄**に `profile.txt` を全部コピペ

この時点では、ただの文字の羅列です。ここから整えます。

### 8. 整形する

**整形メモを開いて、上から順にやるだけです。**

| メモの表記 | やること |
| --- | --- |
| 大見出し | その行にカーソルを置いて、ツールバーの見出しボタン |
| 引用 | その行を選択して、引用ボタン（`"` のアイコン） |
| 太字 | その文を選択して、太字ボタン（`Ctrl+B` / `⌘B`） |
| 区切り線 | その位置にカーソルを置いて、区切り線ボタン |

メモは**作業しやすい順に並べてあります。** 上から順に消し込んでいけば終わります。

> 途中で保存されるので、閉じても消えません。「下書き保存」を押しておくとより安心です。

### 9. 公開設定をする

右上の「**公開に進む**」を押すと、設定画面になります。

| 項目 | 設定 |
| --- | --- |
| ハッシュタグ | `#自己紹介` `#訪問看護` `#看護師` `#人事` |
| マガジン | **追加しない**（自己紹介は連載の記事ではないので） |
| 価格 | 無料 |
| 目次設定 | お好みで。この記事は見出しが多いので、付けると読みやすい |

### 10. 公開する

「投稿する」を押します。おめでとうございます、1本目です。

### 11. プロフィールに固定する

**ここが大事です。**

公開した記事の「…」メニュー、またはプロフィール編集から、**この記事をプロフィールの先頭に固定表示**してください。

これで、あなたのページに来た人が最初に読むのが自己紹介記事になります。

---

## 第3部　マガジンを作る（15分）

自己紹介が終わったら、**連載を入れる箱**を作ります。

### 12. マガジンを作る

1. プロフィールの「マガジン」→「マガジンを作る」
2. 設定はこうします

| 項目 | 入れるもの |
| --- | --- |
| マガジン名 | `人事の失敗図鑑` |
| 説明文 | `launch-kit.md` の「マガジンの説明文」をコピー |
| 画像 | ロゴ（`note/assets/logo.jpg`） |
| 種類 | 無料マガジン |

**連載は必ずマガジンに入れてください。** 1本ずつバラバラだと、2本目以降が読まれません。

## 第4部　第0回を出す（9/1）（30分）

自己紹介と同じ流れです。違うのは2点だけ。

```bash
python3 note/make_note_text.py note/drafts/00-hajimeni.md
python3 note/instagram/make_carousel.py note/instagram/slides/00.txt
```

| 項目 | 自己紹介記事 | 第0回 |
| --- | --- | --- |
| マガジン | 追加しない | **「人事の失敗図鑑」に追加する** |
| ハッシュタグ | `#自己紹介` を含む | `#訪問看護` `#看護師` `#人事` `#採用` |
| 固定表示 | **する** | しない |

**マガジンへの追加を忘れないでください。** ここが連載の生命線です。

公開したら、URL をコピーして各SNSへ。手順は `operations.md` の「STEP 3 連結する」にあります。

## つまずいたときに

| 症状 | 原因と対処 |
| --- | --- |
| 貼り付けたら `**` や `##` が文字で残った | 原案の Markdown をそのまま貼っています。`make_note_text.py` で作った `.txt` のほうを貼ってください |
| 見出し画像の文字が切れる | Instagram 用（1080×1350）を使っています。`note-header.png`（1280×670）に差し替えてください |
| 記事がマガジンに入っていない | 公開後でも追加できます。記事の「…」から編集して、マガジンを選び直してください |
| 予約投稿ができない | note の有料プランが必要な場合があります。使えないなら火曜の朝に手動で公開してください |
| note ID を間違えた | **変更できません。** どうしてもの場合はアカウントを作り直すことになります |

■ 自己紹介記事

□ 整形メモを見ながら整えた

■ マガジン
