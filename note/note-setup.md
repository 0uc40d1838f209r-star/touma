# note をゼロから始めて、最初の記事を出すまで

**所要：初回だけ90分ほど。2本目からは30分です。**

> note の画面のボタン名や配置は変わることがあります。ここに書いた名前と少し違っていても、
> **やることは同じ**なので、近い意味のボタンを探してください。

---

## 第1部　アカウントを作る（20分）

### 1. 登録する

1. [note.com](https://note.com) を開いて「会員登録」
2. メールアドレス、Google、X、Apple のどれかで登録
   - **会社の発信なので、個人のプライベート用アカウントとは分けてください**
3. 届いたメールから認証を済ませる

### 2. クリエイター名と note ID を決める

| 項目 | 入れるもの | 注意 |
| --- | --- | --- |
| クリエイター名 | `元管理者Ns` | あとから変更できます |
| note ID | `moto_kanrisha_ns` など | **あとから変更できません。慎重に** |

note ID は URL になります（`note.com/あなたのID`）。
名刺や求人票に載せることになるので、**短くて読めるもの**にしてください。

### 3. プロフィールを設定する

「設定」→「アカウント設定」から。

**プロフィール画像**
ロゴ（`note/assets/logo.jpg`）を使ってください。
ただし丸く切り抜かれるので、**顔のイラスト部分が中心に来るようにトリミング**してください。ロゴ全体を入れると小さくて読めません。

**ヘッダー画像**
ロゴ全体をそのまま使えます（横長なので相性がいい）。

**プロフィール文**（**140字まで**）

```
訪問看護ステーションの人事。24歳、駅のホームでの電話一本で管理者になりました。訪問看護も管理者もはじめて。4年半やって、今は人を採る側にいます。ここでは自分がやってきた人事の失敗だけを書いています。毎週火曜更新。
```

107字なので収まります。もっと短い版と、X・Instagram・Threads 用は `profile-texts.md` にあります。

> **⚠ ここに自己紹介記事（`drafts/profile.md`）を貼らないでください。**
> あれは約1,860字の**記事**です。140字の欄には入りません。
> 記事のほうは第2部で、独立した1本として公開します。

**リンク**
**採用ページか応募フォームの URL を必ず設定してください。**
投稿を読んだ人が最初に押すのがここです。ここが空だと、興味を持った人の行き先がありません。

**SNS リンク**
X・Instagram のアカウントを登録しておく。相互に行き来できるようにします。

---

## 第2部　最初の記事＝自己紹介を出す（40分）

**1本目は連載ではなく、自己紹介記事です。** これをプロフィールに固定します。

> 第1部で入れた「プロフィール文」（140字）とは別物です。
> **欄に入れる短文＝プロフィール文／記事として公開する長文＝自己紹介記事。** この2つを混同しやすいので注意してください。

### 4. 貼り付け用のテキストを作る

```bash
python3 note/make_note_text.py note/drafts/profile.md
```

`note/note-paste/` に2つできます。

- `profile.txt` ── **記号を抜いた本文。そのまま貼れます**
- `profile-整形メモ.txt` ── 貼ったあとに直す箇所のリスト

### 5. 記事を書く画面を開く

1. 画面右上の「**投稿**」
2. 「**テキスト**」を選ぶ

> 「つぶやき」「画像」ではありません。**必ず「テキスト」**です。

### 6. 見出し画像を入れる

いちばん上の「画像を追加」から、`note/instagram/out/profile/note-header.png` をアップロード。

> **1280×670 の画像を使ってください。**
> Instagram 用のカルーセル画像（1080×1350）は縦長なので、note では上下が切れて文字が読めなくなります。

### 7. タイトルと本文を入れる

1. **タイトル欄**に、整形メモの1行目をコピー
   ```
   【自己紹介】24歳で管理者になって、今は人を採る側にいます
   ```
2. **本文欄**に `profile.txt` を全部コピペ

この時点では、ただの文字の羅列です。ここから整えます。

### 8. 整形する

**整形メモを開いて、上から順にやるだけです。**

| メモの表記 | やること |
| --- | --- |
| 大見出し | その行にカーソルを置いて、ツールバーの見出しボタン |
| 引用 | その行を選択して、引用ボタン（`"` のアイコン） |
| 太字 | その文を選択して、太字ボタン（`Ctrl+B` / `⌘B`） |
| 区切り線 | その位置にカーソルを置いて、区切り線ボタン |

メモは**作業しやすい順に並べてあります。** 上から順に消し込んでいけば終わります。

> 途中で保存されるので、閉じても消えません。「下書き保存」を押しておくとより安心です。

### 9. 公開設定をする

右上の「**公開に進む**」を押すと、設定画面になります。

| 項目 | 設定 |
| --- | --- |
| ハッシュタグ | `#自己紹介` `#訪問看護` `#看護師` `#人事` |
| マガジン | **追加しない**（自己紹介は連載の記事ではないので） |
| 価格 | 無料 |
| 目次設定 | お好みで。この記事は見出しが多いので、付けると読みやすい |

### 10. 公開する

「投稿する」を押します。おめでとうございます、1本目です。

### 11. プロフィールに固定する

**ここが大事です。**

公開した記事の「…」メニュー、またはプロフィール編集から、**この記事をプロフィールの先頭に固定表示**してください。

これで、あなたのページに来た人が最初に読むのが自己紹介記事になります。

## 第3部　マガジンを作る（15分）

### マガジンとは何か

ひとことで言うと、**記事をまとめる本棚**です。

note に投稿した記事は、そのままだと投稿順にバラバラと並ぶだけです。読んだ人は、それが連載だと気づきません。

| | マガジンが無いと | マガジンがあると |
| --- | --- | --- |
| 見え方 | 記事がバラバラに並ぶ | 「人事の失敗図鑑」という1つのまとまりになる |
| 次の回 | 読者が自力で探す（＝探さない） | 一覧から次の回に移動できる |
| 更新 | 気づかれない | **マガジンごとフォローできる。**新しい回が出ると読者に届く |

**要するに、2本目以降を読んでもらうための仕組みです。**
これが無いと、毎週書いても毎回ゼロから読者を集めることになります。

### 1. マガジンを作る画面を開く

**方法A（基本）**

1. 画面右上の自分のアイコンをクリック
2. 「自分のページ」（または「クリエイターページ」）を開く
3. 記事一覧の上にあるタブから「**マガジン**」を選ぶ
4. 「**マガジンを作る**」ボタン

**方法B（見つからないとき）**

記事の公開設定画面にも「マガジンに追加」という欄があり、そこから「**新しいマガジンを作る**」を選べます。
第4部で第0回を公開するときに、その場で作ってしまっても構いません。

> スマホアプリだとボタンの位置が違うことがあります。**最初の1回は PC のブラウザでやるのが確実です。**

### 2. 中身を設定する

| 項目 | 入れるもの |
| --- | --- |
| マガジン名 | `人事の失敗図鑑` |
| 説明文 | 下のブロックをそのままコピー |
| 画像 | ロゴ（`note/assets/logo.jpg`） |
| 種類 | **無料マガジン** |

**説明文（そのままコピーできます）**

```
訪問看護ステーションで人事を見ている元管理者Ns（三井斗真）が、自分がやってきた人事の失敗を書いていきます。

うまくいった話は書きません。あれはどこの会社の採用ページにも載っているので。

24歳のとき、駅のホームで、電話一本で管理者になりました。
訪問看護も、管理者も、はじめてでした。

そこから、今、人を採る側になるまで。失敗は今も続いています。
```

### 3. 「有料マガジン」を選ばないこと

作成時に「無料マガジン」か「有料マガジン」かを聞かれます。**必ず無料を選んでください。**

目的は採用です。読まれないと意味がありません。

> 一度「有料」で作ると、あとから無料に変更できない場合があります。ここは間違えないように。

### 4. 記事をマガジンに入れる

**2つのやり方があります。どちらでも同じです。**

**A. 記事を公開するときに入れる（基本）**

公開設定の画面に「マガジンに追加」という欄があるので、そこで「人事の失敗図鑑」を選ぶ。
**毎週これをやります。** 忘れやすいので、公開ボタンを押す前に必ず確認してください。

**B. 公開したあとに入れる**

- 記事の「…」メニュー →「マガジンに追加」
- または マガジンのページを開いて「記事を追加」

**忘れて公開してしまっても、あとから入れられます。** 慌てなくて大丈夫です。

### 5. 自己紹介記事は入れません

第2部で公開した自己紹介記事は、**マガジンに入れないでください。**

あれは連載の記事ではなく、「私は誰か」の常設ページだからです。
マガジンに入れると、連載を読みに来た人が最初に自己紹介にぶつかって、話の流れが崩れます。

自己紹介記事は**プロフィールに固定表示**、連載は**マガジン**。この置き分けです。

### 6. 並び順に注意する

**マガジンは、新しい記事が上に並びます。**

つまり第0回 → 01 → 02 と出していくと、読者には **02 → 01 → 第0回** の逆順で見えます。

原点編（01〜04）は順に読むと1つの物語になるので、ここは気にしてください。

- マガジンの編集画面に「**並び替え**」があれば、古い順に固定できます
- できない場合でも、**各記事の末尾に「次回は◯◯の話です」と入れてあります**（第0回と01には記入済み）。読者はそれで次に進めます

### 第3部の確認

```
□ マガジン名が「人事の失敗図鑑」になっている
□ 説明文を入れた
□ 画像をロゴにした
□ 無料マガジンになっている
□ 自己紹介記事は入れていない
```

## 第4部　第0回を出す（9/1）（30分）

**第2部（自己紹介記事）とほぼ同じ流れです。** 違うのは3点だけなので、そこだけ気をつけてください。

| | 自己紹介記事 | 第0回 |
| --- | --- | --- |
| マガジン | 追加しない | **「人事の失敗図鑑」に追加する** |
| ハッシュタグ | `#自己紹介` を含む | `#訪問看護` `#看護師` `#人事` `#採用` |
| プロフィール固定 | **する** | しない（自己紹介を固定したままにする） |

### 1. 材料を作る

ターミナルで2行実行します。

```bash
python3 note/make_note_text.py note/drafts/00-hajimeni.md
python3 note/instagram/make_carousel.py note/instagram/slides/00.txt
```

できるもの：

| ファイル | 使い道 |
| --- | --- |
| `note-paste/00-hajimeni.txt` | note の本文にコピペする |
| `note-paste/00-hajimeni-整形メモ.txt` | 貼ったあとの整形の指示 |
| `instagram/out/00/note-header.png` | **note の見出し画像**（1280×670） |
| `instagram/out/00/01〜11.png` | Instagram のカルーセル（1080×1350） |

> 実行できない・よく分からない場合は、こちらで生成済みのファイルをお渡しできます。声をかけてください。

### 2. 記事を作る

第2部の 5〜8 とまったく同じです。

1. 「投稿」→「テキスト」
2. 見出し画像に `out/00/note-header.png` をアップロード
3. タイトル欄に「この図鑑には、私の失敗しか載っていません」
4. 本文欄に `00-hajimeni.txt` を全部コピペ
5. 整形メモを見ながら、上から順に整える

### 3. 公開設定（ここだけ違います）

「公開に進む」を押したら、**マガジンの欄で「人事の失敗図鑑」を選んでください。**

```
□ マガジン ……… 人事の失敗図鑑  ★これが生命線
□ ハッシュタグ … #訪問看護 #看護師 #人事 #採用
□ 価格 ………… 無料
□ 固定表示 …… しない
```

忘れて公開してしまっても、記事の「…」からあとで追加できます。

### 4. 公開したら、URL をコピーする

公開後の記事ページのアドレスをコピーします。`https://note.com/あなたのID/n/xxxxx` の形です。

**この URL を、各SNSの投稿に貼ります。**

### 5. 各SNSに流す

原稿は全部 `distribution.md` にあります。Buffer に4つ予約するだけです。

| 時刻 | 媒体 | 内容 | URL |
| --- | --- | --- | --- |
| 朝 7:30 | X 投稿1 | 冒頭の場面 | **貼らない** |
| 昼 12:00 | Threads | 1投稿 | **貼らない** |
| 夕 18:00 | X 投稿2 | turn ＋ リンク | 貼る |
| 夜 20:00 | Instagram | カルーセル11枚 ＋ キャプション | プロフィール誘導 |

**note を公開してから予約してください。** URL が無いと2投稿目が作れません。

詳しくは `operations.md` の「STEP 3 連結する」に書いています。

## つまずいたときに

| 症状 | 原因と対処 |
| --- | --- |
| 貼り付けたら `**` や `##` が文字で残った | 原案の Markdown をそのまま貼っています。`make_note_text.py` で作った `.txt` のほうを貼ってください |
| 見出し画像の文字が切れる | Instagram 用（1080×1350）を使っています。`note-header.png`（1280×670）に差し替えてください |
| 記事がマガジンに入っていない | 公開後でも追加できます。記事の「…」→「マガジンに追加」から |
| マガジンを作るボタンが見つからない | 自分のページ →「マガジン」タブ。無ければ、記事の公開設定の「マガジンに追加」→「新しいマガジンを作る」からでも作れます |
| マガジンを有料で作ってしまった | 無料に戻せない場合があります。新しく無料マガジンを作り直して、記事を移してください |
| マガジンで記事が逆順に並ぶ | 仕様です（新しい記事が上）。編集画面に「並び替え」があれば古い順にできます。無くても、各記事末尾の「次回は◯◯」で誘導できます |
| 予約投稿ができない | note の有料プランが必要な場合があります。使えないなら火曜の朝に手動で公開してください |
| note ID を間違えた | **変更できません。** どうしてもの場合はアカウントを作り直すことになります |

□ リンクに採用ページ／応募フォームを設定した ★

■ 自己紹介記事
□ make_note_text.py で貼り付け用テキストを作った
□ 見出し画像（1280×670）を入れた
□ タイトルと本文を入れた

□ #自己紹介 を付けた
□ 公開した

■ マガジン
□ 「人事の失敗図鑑」を作った

★ が付いているものは、**後回しにすると効果が測れなくなる**ものです。
