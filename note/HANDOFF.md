## 3. 毎週の作業（火曜の朝）

1. `drafts/` の該当回を開く
2. `python3 note/make_note_text.py` → `note-paste/` に貼り付け用テキストと整形メモが出る
3. `python3 note/instagram/make_carousel.py note/instagram/slides/<回>.txt` → カルーセルと note 見出し画像が出る
4. `distribution.md` の該当節から Instagram キャプションを取る
5. note に貼って整形 → マガジン「人事の失敗図鑑」に追加 → ハッシュタグ → 公開
6. 当日の夜に Instagram

所要は1時間半くらいです。手順の詳細は `operations.md`。

## 4. 絶対に外してはいけないルール

`guardrails.md` と `writing-style.md` に全部書いてありますが、要点だけ。

**書いてはいけないもの**（`guardrails.md`）
- 利用者・ご家族のことは、いかなる形でも書かない
- 元従業員・在籍者が特定される情報を書かない（資格・年齢・性別・前職・入社退職時期・拠点名・担当エリア・家族構成は、**2つ組み合わせると特定されます**）
- 相手の人格を評価しない。主語は常に自分の判断

**書き方**（`writing-style.md`）
- 冒頭は3段：**橋渡し → 失敗の一行 → 場面**。合わせて5行以内
- 1本1,000〜1,500字。turn はひとつだけ
- 毎回、人事の話に着地させる。苦労話で終わらせない
- AI感を消す8つの癖（「〜ではないでしょうか」禁止、抽象名詞は動詞に、感情語は行動に、など）

**この連載の目的は採用です。** 応募数ではなく「入ってから辞めない人が応募してくる」状態をつくること。
裏テーマは「うちは選考で嘘をつかない」ことの証明です。自罰的な反省文で終わる記事は、目的を達成しません。
