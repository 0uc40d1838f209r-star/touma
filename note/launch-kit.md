## 1. 公開の3日前までにやること

### note マガジンを作る

連載は必ずマガジンにまとめてください。1本ずつ独立した記事のままだと、2本目以降が読まれません。

**マガジン名**

```
人事の失敗図鑑
```

**ロゴ**：`assets/logo.jpg`。著者名義は「元管理者Ns」（三井斗真）── 管理者だった人間が、人事として管理者の失敗を語る、という連載の説得力の土台になっているので、名義から外さないこと。

**マガジンの説明文（コピーして使えます）**

```
訪問看護ステーションで人事を見ている元管理者Ns（三井斗真）が、自分がやってきた人事の失敗を書いていきます。

うまくいった話は書きません。あれはどこの会社の採用ページにも載っているので。

24歳のとき、駅のホームで、電話一本で管理者になりました。
訪問看護も、管理者も、はじめてでした。

そこから、今、人を採る側になるまで。失敗は今も続いています。
```

### X のプロフィールを整える

投稿を読んだ人は、必ずプロフィールを見に来ます。**ここが整っていないとフォローされません。**

- 肩書きに「訪問看護ステーションの人事」が入っているか
- 固定ポストに、連載マガジンのリンクを置いたか
- プロフィールのリンクを、採用ページかマガジンにしたか
- 直近の投稿が、連載と関係ない日常投稿で埋まっていないか

### 計測の仕込み（これが最重要）

**この2つがないと、連載が採用に効いているのか永久に分かりません。**

1. 応募フォームに「当社を知ったきっかけ」の自由記述欄を追加する
2. 初回面談の冒頭質問に「note は読みましたか。どの回ですか」を定型で入れる

ダッシュボードを作るより先に、この2つです。

### 記事の中の【 】を埋める

- 事業所名（採用導線の部分）
- 第0回の「代表からもコメントをもらいます」── 代表の名前を出すかどうか
- 「空いた穴でした」を残すかどうかの、代表との合意（01）
- 採用ページ or 応募フォームのリンク
- 代表コメント

## 3. 公開後

### やること

- 面談・面接で「note 読みましたか」を聞き始める（初日から）
- 反応があったコメント・引用を保存しておく。**次の回の題材になります**
- 第2回の下書きに、その日のうちに取りかかる

### やらないこと

- 数字を1日に何度も見る
- 伸びなかったからといって、次回のタイトルを煽り型に変える（`swipe-file.md` 参照）
- 反応がないコメントに反応しに行く

### 想定外の反応があったら

`guardrails.md` の最後に方針が書いてあります。要点だけ再掲します。

- **記事は削除しない。** 訂正は日付入りの追記で行う
- 当事者から指摘が来たら、まず会って聞く。記事上で反論しない
- 窓口は代表と人事副社長の2人に固定。現場スタッフに対応させない
