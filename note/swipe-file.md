## そのまま輸入する「型」6つ

### 型1. 数字を冒頭3行に置く（鳥貴族型）

> 入社1年目の離職率25%。 4人に1人が1年以内に辞めていく。 しかし、今は11.1%。

Before と After を最初の3行に置く。これがフックであり、同時に**記事全体の約束**になる。読者は「その差はどうやって埋めたのか」を読みに来る。

**失敗人事への転用：**
> 3年前、私が採った3人のうち2人が半年で辞めた。 今は、入社した人の◯人に◯人が残っている。 何を変えたのかを書く。

数字がまだ出せないなら、その旨を書けばいい。「今も改善できていない」も立派な数字です。

### 型2. 「×／〇」の対比を1記事に1〜2個入れる

> × 採用を増やせば人手不足は解決する。 〇 採用と定着を両輪で回さないと詰む。
> × どちらか一方をフォローする。 〇 二人の「間の関係」をフォローする。

読者が引用・保存しやすい最小単位。**X 分解の1投稿目にそのまま使えます。**
すでに `guardrails.md` で使っている書き方と同じ形なので、記事本文にも展開してください。

### 型3. 末尾に「保存用チェックリスト」を置く（管理職1年目型）

10のミス記事は末尾に `□` の列を置いていて、これが保存される理由になっています。

**失敗人事版として最も効くのは、求職者側が使えるチェックリストです。**

> 【保存用】訪問看護の面接で、これを聞いてこない会社は危ない
> □ オンコールの頻度と手当を、聞く前に説明されたか
> □ 1日の移動時間と記録時間の実態を数字で言われたか
> □ 同行期間が何日で、何を見るか説明されたか …

自社の宣伝ではなく**業界共通の判断材料**として出すので、応募していない人にも保存されます。
そして、うちが実際にそれを全部やっているなら、それが最強の採用広告になる。

### 型4. 「何を変えたか」を STEP 形式にする（鳥貴族の再現ステップ）

> STEP0. 現状を数字で把握する ／ STEP1. 退職の「順番」を分析する ／ STEP2. サインを可視化する …

④ のブロックを STEP0〜5 で書くと、他社の人事が真似できる形になり、保存・共有されます。
`article-template.md` の ④ に追記済み。

### 型5. 「実践方法」を番号付きで並べる（GAFA記事型）

はけけん氏の記事は「定義 → なぜ効くか → 日系との違い → 実践方法 → 俺の体験」を7回繰り返す構成。
**同じ順番の繰り返しが、長文を読ませています。** 私たちの5ブロック固定と同じ思想なので、型はこのままでいい。

借りるとすれば、④ の中に **番号付きの「実践方法」** を置くこと。読者の持ち帰りが具体になります。

### 型6. コントラスト（肩書きと行動の乖離）

FANZA記事が言っている原理のうち、使えるのはここだけです。「表の顔」と「実際にやっていること」のギャップが人を引き込む。

**そして幸運なことに、この連載はすでに構造がコントラストです。**
「人事の責任者が、自分の人事の失敗を書く」── これ以上のギャップはありません。
だから、**タイトルで煽る必要がまったくない。** 事実を一行にするだけで足ります。

### #05 の ④ は、この線引きがそのまま使える

参考記事が出していた区分は、訪問看護の管理者育成としてかなり正確です。

- **仕組み化できる** … 情報共有／教育導線／記録精度／緊急連絡／法令遵守／業務漏れ防止
- **仕組み化できない** … 空気察知／板挟みの調整／信頼形成／危機予測／感情制御／倫理判断

そして管理者が同時に処理しているものが、医療判断・家族感情・ハラスメント・職員メンタル・労務・法令・営業・多職種調整・緊急対応・看取り・地域関係・事故対応・行政対応。
しかもこれらが**矛盾する**（利用者優先 vs 職員保護／24時間対応 vs 労基法／売上維持 vs 適正算定）。

つまり管理者は「ルール適用者」ではなく**矛盾の調整者**である ── この一行が #05 の結論になります。
「優秀な看護師を管理者にした」失敗は、**プレイヤーの延長線上にない仕事を、延長線上だと思って任せた**という構造で説明できる。

## 輸入しないもの（と、その理由）

集めていただいた素材には、この連載の目的と正面から衝突するものが混ざっています。うまくいっている発信の型でも、**読者が違えば逆に働きます。**

### ✕ 煽り型のタイトル術

「暴露」「禁断」「流出」「※本気の人以外は読まないでください」といった手法です。CTR は確かに上がる。

**しかし、この連載の読者は求職者と、地域のケアマネ・医療機関です。**
煽り型のタイトルで人事の話を書く訪問看護ステーションに、ケアマネは利用者を紹介しません。
連載の目的が「うちは選考で嘘をつかない証明」である以上、**釣りタイトルはその目的を自分で否定します。**

輸入するのは「具体性」と「コントラスト」の**原理だけ**。語彙は輸入しない。

### ✕ 副業・FIRE・入金力系の構成

記事の後半で高額商材に着地する構成です。会社の発信でこれをやると、採用は確実に死にます。
（素材の中では、コミュニケーション5法則の記事が途中から投資・副業の話に変わる構成でした）

### △ Netflix のキーパーテストを、賛同の文脈で引かない

「もしこの社員が辞めますと言ってきたら、必死で引き止めるか。No ならその日のうちに解雇」という考え方です。
論点として触れるのは構いませんが、**訪問看護でこれを肯定的に引用するのは危険です。**

1. 医療・介護は「誰が行っても一定の質が担保される」ことが安全性の前提です。属人性の賛美は、事業の安全設計と噛み合わない
2. 「あなたの替えはいる」というメッセージは、**一人で家に上がる仕事の心理的安全性を直接壊します**
3. 日本の労働法制とも噛み合わない

#12（辞める人を引き止めた失敗）で「引き止めの基準」を書くときに、**反対の立場として引く**なら成立します。

### ✕ X のスクレイプを一次ソースとして引用しない

これは実務上いちばん危ない点です。

- 鳥貴族の「25% → 11.1%」という数字
- 藤田氏の発言（**元記事自身が「語ったとされている言葉」と書いています**）
- 豊田章男氏のメッセージ全文

これらはすべて、X の投稿から取ったテキストです。数字の年度や前提条件、発言の正確さは検証されていません。

**他社の数字や実在の経営者の発言を、会社名義の note に載せるなら、必ず一次ソースに当たってください。**
公式リリース、有価証券報告書、書籍、本人の投稿、取材記事。

間違った数字を引いて指摘されたら、それは連載の次の回のネタになるどころか、**連載の信用そのものが飛びます。**
安全なのは、他社事例を数字なしで「◯◯社の事例で紹介されていた考え方」として構造だけ借りるか、一次ソースを確認して出典付きで書くかの二択です。

## X 運用（「炎上なしで伸ばす」記事から）

「今後発信を続けていけるように」という当初の課題に、いちばん直接効く素材でした。輸入する5点。

1. **自分にしか出せない一次情報を出す。** 専門性や実績がなくても、「誰よりも自分の失敗を記録している人」は一次情報です。この連載はその条件をすでに満たしています
2. **アカウントの純度を保つ。** 人事副社長のアカウントに日常投稿を混ぜない。フォロワーが求めていない投稿は、伸びないだけでなくアカウントの定義をぼかします
3. **逆三角形で書く。** 冒頭の一文が命。「オンボーディング設計の重要性について」ではなく「入社初日に『じゃあ明日から同行お願いします』と言った」から始める
4. **一般層が入れる入口から入り、専門で着地する。** 「失敗人事」は入口が誰にでも分かり、着地が訪問看護の実務。**構造がすでに正しい**ので、余計な工夫は不要です
5. **プロフィール遷移を作る。** 投稿を読んだ人が「この人は何者か」を見に行く。プロフィールに採用リンクと連載マガジンを置く。**これは第1回公開前に整えておくこと**

投稿前チェック（`article-template.md` の X 分解と併せて使う）：

```
□ 自分にしか出せない一次情報が入っているか
□ 冒頭一文だけで意味が通るか
□ 初見の人にも単体で伝わるか
□ この投稿は、うちで働くか迷っている人の役に立つか
□ 煽っていないか
```
