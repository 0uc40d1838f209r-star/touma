# 公開前ガードレール

**毎回、公開ボタンを押す前にこの文書を上から読むこと。**

「失敗人事」は、必ず自分以外の誰かが登場するテーマです。辞めた人、辞めさせた人、今も在籍している人。
そして訪問看護は、利用者・ご家族という**絶対に触れてはいけない第三者**が背後にいる事業です。
連載が採用に効くかどうか以前に、ここを踏み外すと事業そのものが傷つきます。

---

## 絶対禁止（例外なし）

### 1. 利用者・ご家族に関する情報は、いかなる形でも書かない

疾患、年齢、家族構成、地域、訪問時のエピソード、「あるお宅で」レベルの記述もすべて不可。
ぼかしても不可です。守秘義務と個人情報保護法の問題であると同時に、**「この会社は利用者のことを外で話す」と一度でも思われたら、
ケアマネからの紹介は止まります**。営業活動が積み上げてきたものが消えます。

人事の失敗を語るのに利用者の話は要りません。必要になったと感じたら、それは記事の構成が間違っています。

### 2. 元従業員・在籍者が特定される情報を書かない

訪問看護の地域コミュニティは狭い。**単独では特定できない属性でも、2つ組み合わせると特定されます。**

書かない属性：資格の種類 / 年齢・年代 / 性別 / 前職 / 入社・退職の時期 / 拠点名 / 担当エリア / 家族構成 / 特徴的な発言の言い回し

> ✕「昨年入社した30代の男性理学療法士が」
> ○「あるスタッフが」／「入社して間もないメンバーが」

### 3. 相手の人格を評価しない。主語は常に自分の判断

この連載の主語は最初から最後まで「私」です。

> ✕「彼女はコミュニケーションに難があった」
> ○「私は、面接で本人が語った内容を、そのまま現場での行動として起きると思い込んでいた」

「辞めた人が悪かった」構図の記事は、採用に**マイナスに**働きます。読者は求職者です。
「この会社は、辞めた人のことを外でこう書くのか」と読まれた瞬間に応募は消えます。

---

## 必ずやること

### 4. 複数の事例を1つに束ね、その旨を明記する

似た失敗を2〜3件まとめて1つのケースとして書く。特定を防げるうえに、原因分析が普遍化して記事の価値も上がります。
記事末尾に定型文を入れる：

> ※ 本稿の事例は、個人が特定されないよう複数の出来事を再構成しています。

### 5. 「在籍者が全員読む」前提で書く

名指ししていなくても、当事者と周囲は**必ず**自分のことだと分かります。
社内の誰かが読んで「あれは自分のことだ」と傷つく記事は、採用に効いても組織を痛めます。差し引きで赤字です。

- 当事者が **在籍中** → 公開前に本人に見せる。渋られたら書かない。
- 当事者が **退職済み** → 4のルールで完全に束ねる。連絡が取れて関係が良好なら一言通す。

### 6. 数字は出す。ただし個人が割れる粒度では出さない

「3人採用して2人辞めた」は誠実さの証明になります。
「◯◯拠点で昨年度の退職者が2名」は個人が割れます。粒度は全社・年単位まで。

### 7. 公開前チェックは2人。24時間寝かせる

1. 代表
2. 当事者に近くないメンバー1名（「これ誰のことか分かる？」だけを聞く）

書いた直後は必ず筆が走っています。**下書き完成から公開まで最低24時間空ける。**

### 8. 実名・実事例を含む下書きは、このリポジトリに置かない

このリポジトリは公開されています。実名や生の事例を含む下書きは `note/private/`（`.gitignore` 済み）に置くこと。
`note/drafts/` に置いてよいのは、固有名詞と特定可能な事実を抜いた骨格だけです。

## 公開前チェックリスト（コピーして毎回使う）

```
□ 利用者・ご家族に関する記述が1文字もない

□ 他人の人格を評価している文がない（主語がすべて「私」になっている）
□ 「④何を変えたか」に、実在する具体物が書かれている
□ 「⑤まだ解けていない宿題」を書いた
□ 再構成の但し書きを入れた
□ 在籍中の当事者がいる場合、本人の了解を取った
□ 代表チェック済み
□ 第三者に「誰のことか分かる？」と聞いて「分からない」と言われた
□ 下書き完成から24時間以上経っている
```

## 想定外の反応があったときの方針（先に決めておく）

- **記事は削除しない。訂正は追記で行う。** 消すと「都合が悪くなったら消す会社」になり、連載の前提が崩れます。
- 当事者から指摘が来たら、まず会って聞く。記事上で反論しない。
- 事実誤認があった場合は、記事冒頭に日付入りで訂正を追記する。
- 対応の窓口は代表と人事副社長の2人に固定し、現場スタッフに対応させない。
