# 【失敗人事 #03】「なぜ出すんですか」と、私は最後まで聞かなかった

スタッフが、やっと5人になったところでした。

そのタイミングで、別のエリアに事業所を出すことが決まりました。

正直に言います。当時、まったく意味が分かりませんでした。

## 訳が分からなかった

まだこっちが整っていないのに、なぜ新しいところを作るんだろう。

人も足りていない。今いる5人で、今のエリアをようやく回している状態です。
そこから人を割いて別の場所に出すというのは、当時の私の目には、**わざわざ薄くする**ようにしか見えませんでした。

決まったことは決まったこととして動きました。動きましたが、腹には落ちていませんでした。

## 今なら、少しは分かります

あれから何年か経って、少しは分かるようになりました。

利用者さんのエリアは、放っておいても広がっていきます。遠いところからの依頼が増えてきたら、そこに拠点があるかないかで、受けられる件数がまったく変わる。

それに、スタッフに勢いがあるうちに出す、という判断もあります。人が育ってから出そうとすると、たいてい機を逃す。

だから、あの判断そのものが間違っていたとは、今は思っていません。

**問題は、そこではありませんでした。**

## 私が本当に欲しかったもの

当時の私が欲しかったのは、「出すな」という結論ではありません。

**なぜ、いま、そこに出すのか。何を基準にそれを決めたのか。**

それだけでした。

件数の見込みなのか。エリアの需要なのか。人の育ち具合なのか。それとも、もっと別の何かなのか。
基準さえ分かっていれば、私は納得して動けたはずです。

そして、次に自分が同じ判断をする番になったとき、その基準を使えたはずでした。

## なぜ、聞かなかったのか

（ここが、この回の本題です）

ここまで読んで、当然の疑問が出ると思います。

**聞けばよかったじゃないか。**

その通りです。聞けばよかった。

私は聞きませんでした。当時、自分にはこう説明していました。

- 経営が決めたことだから
- 自分は現場の人間だから
- 忙しかったから

三つとも、後から付けた理由です。

本当の理由は、別にありました。

**分かっていないと思われるのが、怖かったんです。**

## 前回と、同じ場所でつまずいている

第1回に、私は「何か失敗しても隠そうとした」と書きました。分かっているふりをしようとした、と。

第2回では、話しにくい相手のことを「分からない」と思ったまま、分からないままにした、と書きました。

そして今回も、同じです。

分かっていないことを、分かっていないと言えなかった。

私は3回続けて、同じところで転んでいます。
制度が分からないときは、あれだけ調べたのに。判断が必要なときは、その日のうちに決めていたのに。

**自分の無知が露見する場面だけ、私は毎回逃げていました。**

## いま、私は決める側にいます

今、私は人事として、人を採る計画を立てる側にいます。
拠点をどうするか、そこに何人置くかという話にも、関わる立場になりました。

つまり、あのとき私が説明を求めた相手の側に、私が座っています。

だから、自分に聞かなければいけません。

**私は今、あのときの自分に説明できる形で決めているだろうか。**

- 出すか出さないかを、何で判断しているのか。基準は言葉になっているか
- その基準を、現場のスタッフに説明しているか。いつ、どこで、誰に
- 採用の計画は、出す決裁の前に立てているのか、後に立てているのか
- 決まったことだけを伝えて、決め方を伝えないまま済ませていないか

【④ここに、今やっていることを入れる ← 末尾「この回の課題」参照】

## まだ解けていない宿題

書きながら気づいたことがあります。

私は「説明がなかった」と書いてきました。でも、**説明を求めなかったのも私です。**

経営が説明していなかったのか、私が受け取れる状態になかったのかは、正直に言うと、今でも分かりません。
説明されていたのに、当時の私に読み解く力がなかっただけかもしれない。

そしてもう一つ。

今、私が決めたことを、当時の私と同じように「訳が分からない」と思っている人が、うちのどこかにいるはずです。
その人は、たぶん私に聞いてこない。当時の私が聞かなかったのと、同じ理由で。

## 【保存用】決まったことを現場に降ろすときの6つ

私が「されなかった」と感じたことの裏返しです。決める側の人へ。

```
□ 決まった結論だけでなく、「何を基準に決めたか」を一緒に伝えた
□ その判断で、現場の誰の仕事がどう変わるかを具体的に言った
□ 「なぜ今なのか」を説明した
□ 質問できる場を、伝えた直後に用意した
□ 質問が出なかったとき、それを「納得」と読まなかった
□ 半年後に「あのとき何が分からなかったか」を聞きに行った
```

最後の1つが、いちばん効きます。
その場では誰も聞きません。私も聞きませんでした。

# この回の課題【要対応】

## 1. この回は、代表と一緒に作ってください

構造上、**代表への公開質問**になっています。事前に渡さず出すのは絶対に避けてください。

そのうえで言うと、**この回は連載でいちばん強くなり得ます。**
「聞けなかった側」だった人が「決める側」になり、その二人が同じ記事に並ぶ。
これは他社が真似できません。真似するには、経営者が自分の判断を公開の場で説明する覚悟が要るからです。

## 2. ④「何を変えたか」に入れるもの

この回は ④ を作りやすい構造です。今のご自身の実務から、答えられるものを教えてください。

- 拠点を出すかどうかの判断基準を、言葉にしているか（していないなら、それも答えです）
- 採用計画は、開設の決裁の前と後、どちらで立てているか
- 決まったことを現場に降ろすとき、決め方も一緒に降ろしているか
- 「あのとき何が分からなかったか」を後から聞きに行ったことがあるか

**まだ何もしていないなら、この記事を書くことをきっかけに一つ始めて、それを書くのがいちばん誠実です。**
「この記事を書きながら、◯◯を始めました」という一文は、後付けの改善策より強く読まれます。

## 3. 拠点名を出すかどうか

原案では「別のエリア」としています。
拠点名を出すと、その拠点で働いている人が「自分たちの店は納得されずに作られたのか」と読む可能性があります。
**伏せたままを推奨します。**

## 4. 順番について

第2回（溝の話）の ④ がすぐ埋まらない場合、**この回を第2回に繰り上げる**ことをおすすめします。
この回は ④ を作りやすく、代表コメントも強い。連載の勢いを落とさずに済みます。

## 5. 意味のない細部を1つ

- サテライトの話を聞かされたのが、どこで、どんな場だったか（会議、立ち話、朝礼）
- そのとき自分が何を思ったか以外の、周りの人の反応
- 新しい事業所を初めて見に行った日のこと
