# 【失敗人事 #02】気づいたら、事業所が二つに割れていた

人が増えるのは、いいことだと思っていました。

同い年のスタッフが入って、リハビリの責任者として経験のある人が来てくれて、事業所に人が増えました。
私はそのとき、どうすればこの人たちとうまくやれるか、どうすれば話ができるかを考えていました。

考えていたのに、割りました。

## 三人から、増えた

前回書いたとおり、この事業所は三人から始まりました。
事務がひとり、看護師がひとり、そして何も分かっていない25歳の管理者です。

そこから何年かして、人が増えました。

同い年のスタッフがひとり。そして、リハビリの責任者として、経験のある人が来てくれました。

人が増えたら管理が楽になる、とは思っていませんでした。人が増えれば、決めることも増える。それは分かっていました。
だから私は、どうすればこの人たちとうまくやれるかを考えていた——つもりでした。

つもりでした、と書くのは、実際には何もしていなかったからです。

## 話せませんでした

リハビリの責任者と、私はうまく喋れませんでした。

嫌いだったわけではありません。対立していたわけでもない。
ただ、話が続きませんでした。

【※ここは末尾の「解像度」を読んでから確定してください】
シフトの確認はします。利用者さんの情報共有もします。必要なことは伝えている。
でも、それだけでした。「何を考えているんですか」と聞いたことは、一度もありません。

何を考えているのか分からない、と私は思っていました。

今にして思えば、向こうも同じことを思っていたはずです。

当時の私は、まだ幼かった。自分より経験のある専門職に対して、どう向き合えばいいのか分かっていませんでした。
分からないから、必要なこと以外は話さなくなりました。

## 誰が割ったのか

気がついたら、事業所は二つのかたまりになっていました。

リハビリのスタッフと、看護のスタッフ。
それぞれで固まって、それぞれで話して、それぞれで動く。

最初、私はこれを**職種の違い**だと思っていました。

リハビリと看護は、見ているものが違います。使う言葉も違う。訓練の話と医療管理の話は、どうしても噛み合わないところがある。だから分かれるのは仕方がない、と。

次に、**人数のせい**だと思いました。

三人のときは全員で話していたのが、人が増えて話しきれなくなった。組織が大きくなればそうなる。よくあることだ、と。

三つ目に、**責任者の人柄のせい**にしかけたこともあります。これは書くのが恥ずかしいですが、事実です。

三つとも、違いました。

## 手がかり

事業所が割れていることに気づいてから、自分が何をしていたかを振り返りました。

そこで分かったことがあります。

私は、リハビリの責任者と、**一度もちゃんと話していませんでした。**

伝えるべきことは伝えている。連絡も、共有も、抜けはない。
でも、話してはいませんでした。

分からない、と思ったまま、分からないままにしていた。

## 私が割ったんです

前回、私はこう書きました。

> うやむやにしない人間のところに、決めなければいけないことは集まってくる

分からないことは分からないと言って、調べて、その日のうちに返す。それが管理者としての私のやり方でした。

でも、あれは業務の話です。

制度が分からなければ調べます。加算の要件があいまいなら確認します。利用者さんのことで判断がつかなければ、その場で決めます。

**人のことだけは、うやむやにしていました。**

話しにくい相手とは、話さない。分からない人のことは、分からないままにする。

業務であれだけ「うやむやにしない」と言っていた人間が、いちばん時間のかかることだけは先送りにしていた。

溝は、職種が作ったのでも、人数が作ったのでもありません。
**私が話さなかったから、空いたんです。**

## どう収めたか

最終的に、私たちは「お互いの部署が、それぞれ責任を持ってやろう」というところに落ち着きました。

うまくいったのか、と聞かれると、答えに困ります。

事業所は回るようになりました。それぞれの部署が自分の領域に責任を持つようになって、業務としては前より整いました。

でも、溝が埋まったわけではありません。

**話せないまま、分けることで収めた。**

これは解決ではなく、分離です。当時の私にはそれが精一杯でしたし、今でもそう思っています。

【④ここに、今やっていることを入れる ← 末尾の「この回の課題」参照】

## まだ解けていない宿題

正直に書きます。この回には、きれいな答えがありません。

分けたことで業務は回りました。でも、分けなければ何が起きていたのかは、今も分かりません。
そして、あのとき私が一度でも「何を考えているんですか」と聞いていたら何が変わったのかも、確かめようがありません。

【もし、その後に何か変わったこと・今も引きずっていることがあれば、ここに1つ】

## 【保存用】職種の違う責任者を迎える管理者へ

私は、これを一つもやりませんでした。だから溝が空きました。

```
□ 着任後1ヶ月以内に、業務以外の話を1回した
□ 「何を考えているんですか」と、直接聞いた
□ その職種が何を大事にしているかを、こちらから聞きに行った
□ 決め方（誰が何を決めるか）を、着任時に握った
□ 部署をまたぐ議題を扱う場を、定例で作った
□ スタッフが「どちらに聞けばいいか」で迷っていないか確認した
```

半分もできていないなら、溝はもう空き始めています。私がそうでした。

# この回の課題【要対応】

## 1.「うまく喋れなかった」の解像度【いちばん大事】

ご指摘のとおりです。「喋れなかった」だけでは、読者は何が起きていたのか想像できません。
**4つのうちどれだったのかで、この記事の意味がまったく変わります。**

下から選んでください。本文の該当箇所を、そのまま入れ替えられる形にしてあります。

### A. 業務連絡だけはしていた（今の本文はこれ）

```
シフトの確認はします。利用者さんの情報共有もします。必要なことは伝えている。
でも、それだけでした。「何を考えているんですか」と聞いたことは、一度もありません。
```

→ いちばん多いパターン。「連絡はしていたから、話していたつもりになっていた」という失敗になります。

### B. 話しかけたが、続かなかった

```
何度か、話しかけてはいました。
訓練のこと、利用者さんのこと。でも、二言三言で終わる。
そのうち私は、話しかける回数を減らしました。減らしたことにも、しばらく気づいていませんでした。
```

→ 「一度は行動した。でも続けなかった」という失敗。**読者がいちばん自分に重ねやすいのはこれです。**

### C. 一度ちゃんと話して、失敗した

```
一度だけ、二人で話す時間を取ったことがあります。
【そのとき何を話して、どう終わったか】
それ以来、私はその話題に触れなくなりました。
```

→ **これが事実なら、この回はいちばん強くなります。** 具体的な失敗の場面が入るからです。
　もしそういう場面があったなら、覚えている範囲で教えてください。書き起こします。

### D. ほとんど話していなかった

```
思い返してみると、業務以外の話をした記憶がありません。
朝の挨拶と、必要な連絡だけ。それが何年か続きました。
```

→ いちばん厳しい書き方ですが、事実ならこれがいちばん誠実です。

**この4つのどれか、教えてください。**
思い出すための質問：**一度でも、二人だけで話した場面はありましたか。** あるなら、そのとき何を話して、どう終わりましたか。

## 2. ④「何を変えたか」が素材にありません

いただいた素材では、この件は「お互いの部署が責任を持とう」で終わっています。**つまり、解けていません。**

第1回に続いて2本目も ④ が空だと、連載が反省文に見え始めます。
下のどれか1つでも今やっていることがあれば、教えてください。記事に入れます。

- 職種の違う責任者と、今は何を決めて話しているか（頻度・場・議題）
- 部署をまたぐ議題を扱う定例があるか
- 溝ができる前に気づくために、何を見ているか（会話量、報告の減り方、休憩の取り方）
- 職種をまたぐ人を採用するとき、選考で何を確認するようになったか
- あのとき分けたことが、その後どうなったか（統合したのか、そのままなのか）

**「今もできていません」でも構いません。**その場合は「宿題」に寄せて書き、持ち帰りは【保存用】に担わせます。
ただし、その形は**この回までにしてください。**

## 3. 順番の入れ替えも選べます

④ がすぐ埋まらないなら、**第3回（サテライトの話）を先に出す**手があります。
あちらは「今、決める側になった自分」に接続できるので ④ を作りやすく、代表コメントも強い。連載の勢いを落とさずに済みます。
