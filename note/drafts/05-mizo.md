# 気づいたら、事業所が二つに割れていた

人が増えるのは、いいことだと思っていました。

同い年のスタッフが入って、リハビリの責任者として経験のある人が来てくれて、事業所に人が増えました。

私はそのとき、どうすればこの人たちとうまくやれるかを考えていた——つもりでした。

つもりでした、と書くのは、実際には何もしていなかったからです。

---

リハビリの責任者と、私はうまく喋れませんでした。

嫌いだったわけではありません。対立していたわけでもない。
ただ、話が続きませんでした。

【▼差し替え候補あり】
シフトの確認はします。利用者さんの情報共有もします。必要なことは伝えている。
でも、それだけでした。「何を考えているんですか」と聞いたことは、一度もありません。

何を考えているのか分からない、と私は思っていました。
今にして思えば、向こうも同じことを思っていたはずです。

---

気がついたら、事業所は二つのかたまりになっていました。

リハビリのスタッフと、看護のスタッフ。
それぞれで固まって、それぞれで話して、それぞれで動く。

最初、私はこれを職種の違いだと思いました。見ているものが違うのだから、分かれるのは仕方がない、と。

次に、人数のせいだと思いました。三人のときは全員で話せていたのが、増えて話しきれなくなった。よくあることだ、と。

三つ目に、責任者の人柄のせいにしかけたこともあります。書くのが恥ずかしいですが、事実です。

三つとも、違いました。

---

前に、私はこう書きました。

> うやむやにしない人間のところに、決めなければいけないことは集まってくる

制度が分からなければ調べます。加算の要件があいまいなら確認します。
利用者さんのことで判断がつかなければ、その場で決めます。

でも、あれは業務の話でした。

**人のことだけは、うやむやにしていたんです。**

話しにくい相手とは、話さない。分からない人のことは、分からないままにする。
いちばん時間のかかることだけを、私は先送りにしていました。

溝は、職種が作ったのでも、人数が作ったのでもありません。
**私が話さなかったから、空いたんです。**

---

最終的に、私たちは「お互いの部署が、それぞれ責任を持ってやろう」というところに落ち着きました。

事業所は回るようになりました。業務としては、前より整いました。

でも、溝が埋まったわけではありません。

話せないまま、分けることで収めた。
これは解決ではなく、分離です。今でもそう思っています。

# 判断が必要なこと

## 1.「うまく喋れなかった」の解像度【いちばん大事】

「喋れなかった」だけでは、読者は何が起きていたのか想像できません。
**どれだったのかで、このコラムの意味がまったく変わります。** 本文の【▼】をそのまま入れ替えられる形にしました。

### A. 業務連絡だけはしていた（今の本文）
```
シフトの確認はします。利用者さんの情報共有もします。必要なことは伝えている。
でも、それだけでした。「何を考えているんですか」と聞いたことは、一度もありません。
```
→「連絡はしていたから、話していたつもりになっていた」という失敗になります。

### B. 話しかけたが、続かなかった
```
何度か、話しかけてはいました。訓練のこと、利用者さんのこと。
でも、二言三言で終わる。
そのうち私は、話しかける回数を減らしました。
減らしたことにも、しばらく気づいていませんでした。
```
→ 一度は行動した。でも続けなかった。**読者がいちばん自分に重ねやすい形です。**

### C. 一度ちゃんと話して、失敗した
```
一度だけ、二人で話す時間を取ったことがあります。
【そのとき何を話して、どう終わったか】
それ以来、私はその話題に触れなくなりました。
```
→ **これが事実なら、このコラムはいちばん強くなります。**

### D. ほとんど話していなかった
```
思い返してみると、業務以外の話をした記憶がありません。
朝の挨拶と、必要な連絡だけ。それが何年か続きました。
```
→ いちばん厳しい書き方ですが、事実ならこれがいちばん誠実です。

**思い出すための質問：一度でも、二人だけで話した場面はありましたか。**
あるなら、何を話して、どう終わりましたか。

## 2. 今やっていることが1つでもあれば、末尾に2〜3行

短編コラムなので、長い解決策は要りません。**2〜3行で足ります。**

- 職種の違う責任者と、今は何を決めて話しているか
- 部署をまたぐ議題を扱う定例があるか
- あのとき分けたことが、その後どうなったか（統合したのか、そのままなのか）

「今もできていません」でも構いません。ただ、**3本続けて何も変えていないと、読者は離れます。**

## 3. 確認事項

- 「人が増えたころ、当社はまだまだ〇〇なかった」は**「自分がまだまだ幼かった」**という意味で合っていますか
- リハビリの責任者は**今も在籍**していますか。在籍中なら、公開前に本人に見せてください

## 4. あと1つ入れるなら

**二つに分かれていることに気づいた瞬間**を一行。
休憩室の座り方、朝礼の立ち位置、飲み会の席順。何を見て気づいたか。
