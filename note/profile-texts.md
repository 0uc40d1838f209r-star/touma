# プロフィール文（各SNS）

> **「自己紹介」には2種類あります。混同しやすいので、先に分けます。**
>
> | | 何か | 文字数 | 置き場所 |
> | --- | --- | --- | --- |
> | **プロフィール欄** | 設定画面に入れる短い紹介文 | **note は140字まで** | アカウント設定 |
> | **自己紹介記事** | 経歴を書いた1本の記事（約1,860字） | 制限なし | 記事として公開し、プロフィールに固定 |
>
> `drafts/profile.md` は**記事のほう**です。プロフィール欄には入りません（入れようとすると140字で切れます）。
> このファイルにあるのが、**欄に入れるほう**です。

---

## note（140字まで）

**107字**

```
訪問看護ステーションの人事。24歳、駅のホームでの電話一本で管理者になりました。訪問看護も管理者もはじめて。4年半やって、今は人を採る側にいます。ここでは自分がやってきた人事の失敗だけを書いています。毎週火曜更新。
```

### もっと短くしたい場合

**84字**

```
訪問看護ステーションの人事。24歳、駅のホームでの電話一本で管理者になりました。自分がやってきた人事の失敗だけを書いています。うまくいった話は書きません。毎週火曜更新。
```

**58字**

```
訪問看護ステーションの人事。自分がやってきた人事の失敗だけを書いています。うまくいった話は書きません。毎週火曜更新。
```

> **どれを選んでも構いませんが、「失敗だけを書いています」は必ず残してください。**
> ここがこのアカウントの定義です。ここが無いと、ただの人事アカウントになります。

## X（160字まで）

**108字**

```
訪問看護ステーションの人事｜24歳、駅のホームでの電話一本で管理者に。訪問看護も管理者もはじめてでした｜自分がやってきた人事の失敗だけを書いています。うまくいった話は書きません｜note「人事の失敗図鑑」毎週火曜更新
```

X は改行が使えないので、`｜` で区切っています。

## Instagram（150字まで）

**84字**

```
訪問看護ステーションの人事
24歳、電話一本で管理者になりました
自分がやってきた人事の失敗だけを書いています
うまくいった話は書きません
毎週火曜更新 ↓全文はこちら
```

Instagram は改行が効くので、1行1メッセージにしています。
末尾の「↓全文はこちら」の下に、**リンク欄でマガジンの URL** を設定してください。

## 表示名（すべて共通）

```
元管理者Ns
```

会社名や本名を表示名に入れないでください。**検索でも一覧でも「元管理者Ns」で一貫させる**ほうが、覚えられます。
実名（三井斗真）は、自己紹介記事の本文で名乗ります。

---

## リンク欄（すべて共通）

**採用ページか応募フォームの URL。**

投稿を読んだ人が最初に押すのがここです。**空にしないでください。**
まだ採用ページがないなら、暫定でマガジンの URL を入れておいて、できたら差し替えてください。
