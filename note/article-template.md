# 記事テンプレート（短編コラム）

**1本＝1,000〜1,500字。ひとつの場面、ひとつの turn。**

長く書けば深くなるわけではありません。むしろ逆で、**短いほうが最後まで読まれ、最後まで読まれたものだけが人を動かします。**
以前このテンプレートは「5ブロックのケーススタディ・2,500〜4,000字」でしたが、読み手の負担が大きすぎたので、短編コラムに変えました。

---

## 型

```markdown
# （タイトル：因果か、問いを一行で）

（① 場面：3〜6行）
いきなり場面から始める。前置き・自己紹介・業界の一般論は書かない。
セリフがあるなら、それを1行目に置くのがいちばん強い。

---

（② 状況：5〜10行）
何が起きていたのか。数字が出せるなら1つ入れる。
**評価と反省をここに混ぜない。** 事実と、当時の自分の目線だけ。

---

（③ 問い、または誤った答え：5〜10行）
「なぜだろう」と思ったこと。あるいは、当時の自分が出していた間違った答え。
**ここが読者を引っ張ります。** 短いコラムでも、謎はいる。

---

（④ turn：5〜10行）
気づいたこと。ひっくり返る場所。**1本に1つだけ。**
2つ入れると、どちらも弱くなります。

---

（⑤ 着地：3〜6行）
今の自分に引きつけて終わる。
きれいにまとめない。**解けていないことを1行残す。**

---

**元管理者Ns**（三井斗真）／訪問看護ステーションの人事
24歳のとき、駅のホームで、電話一本で管理者になりました。
このマガジンでは、私がやってきた人事の失敗を順番に書いています。
```

**自己紹介は末尾の署名だけ。** 毎回冒頭で名乗ると、それだけで読者が離れます。

---

## 長さの目安

| 部分 | 行数の目安 |
| --- | --- |
| ① 場面 | 3〜6行 |
| ② 状況 | 5〜10行 |
| ③ 問い／誤った答え | 5〜10行 |
| ④ turn | 5〜10行 |
| ⑤ 着地 | 3〜6行 |
| 署名 | 3〜4行 |

**合計で1,000〜1,500字。** 1,800字を超えたら、2本に割ることを考えてください。
実際、第1回は最初4,000字近くありました。割ったら4本になり、全部が読みやすくなりました。

---

## 書くときのルール

| ルール | 理由 |
| --- | --- |
| 1本に turn は1つだけ | 2つ入れると、どちらも弱くなる |
| 場面から始める。セリフがあれば1行目に | 前置きを読む人はいない |
| 主語は常に「私」 | `guardrails.md` 3。他人の人格評価は連載を殺す |
| 数字を1つ | 具体性が誠実さの証拠になる |
| 段落を短く。1行だけの段落を混ぜる | スマホで読まれる。改行が呼吸になる |
| 見出しは付けても2つまで | 短いコラムに小見出しを並べると、逆に読みにくい |
| きれいにまとめない | 解けていない一行が、次を読ませる |
| 人事用語を減らす | 「エンゲージメント」は読者の現場語ではない |

## 「何を変えたか」はどこへ行ったか

以前の型では ④「何を変えたか」に、面接の質問文やチェックリストといった**実在する具体物**を必ず書く決まりでした。
短編コラムでは、それを毎回入れると長くなります。

**分担を変えます。**

- **コラム本体** … 場面と気づき。長い解決策は書かない。書くなら末尾に2〜3行まで
- **数本に1本、実務回を挟む** … 「うちの面接で必ず聞く3つの質問」のように、仕組みだけを短く出す回
- **【保存用】チェックリスト回** … 求職者や他社の人事がそのまま使えるものを、独立した1本にする

これで、コラムは読みやすいまま、連載としては「ちゃんと変えている会社」だと伝わります。

**目安は、3本に1本。** 場面のコラムが2本続いたら、次は仕組みの回を出してください。

## タイトルの型

`因果か、問いを一行で`。連番は付けず、マガジンで順番を管理します。

- ○ 「やります、と答えたのは、電車に早く乗りたかったからです」
- ○ 「なぜ、みんな私に聞きに来たのか」
- ○ 「毎日、怒られていました」
- ✕ 「人事における登用の難しさについて」（人事用語が主語／因果も問いもない）
- ✕ 「managerの選び方、3つのポイント」（ノウハウ記事に見えて、この連載の価値が消える）

## X への分解（公開当日）

短編コラムなら、**2投稿で足ります。**

1. **場面** — コラムの ① をそのまま。リンクは貼らない
2. **turn ＋ リンク** — ④ の要点と note のリンク

間隔は3〜4時間。1投稿目にリンクを置かない。

投稿前チェック：

```
□ 自分にしか出せない一次情報が入っているか
□ 冒頭一文だけで意味が通るか
□ 初見の人にも単体で伝わるか
□ うちで働くか迷っている人の役に立つか
□ 煽っていないか
```

> 参考記事から輸入した型の根拠は `swipe-file.md` にまとめてあります。
> **煽り型のタイトル術は輸入しません。** 理由も同ファイルに書いています。
