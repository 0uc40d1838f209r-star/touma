# 配信設計（note / X / Threads / Instagram）

Buffer で複数媒体に配信する前に、**媒体ごとに誰がいて、何を取りに行くのか**を決めておかないと、
どこも伸びないまま作業量だけが増えます。

---

## 1. 媒体ごとの役割

| 媒体 | そこにいる人 | この連載で取りに行くもの | 出す形 |
| --- | --- | --- | --- |
| **note** | 記事を読みに来た人 | 読了・保存・**応募** | 1,000字のコラム（本体） |
| **X** | 人事・経営者・同業の訪問看護 | 業界内の信頼、被取材、提携、間接的な口コミ | 本文からの抜粋2投稿 |
| **Instagram** | **看護師・セラピスト本人** | **実際の応募** | 文字カルーセル 9〜10枚 |
| **Threads** | Instagram の人がテキストで話す場所 | 会話と反応。追加コストがほぼゼロ | 1投稿（X よりやわらかく） |

**X と Instagram は、読者がまったく違います。**

X にいるのは主に、人事や経営をやっている人と同業者です。ここで積み上がるのは「業界内の信頼」で、
採用には**間接的に**効きます（同業からの紹介、取材、提携）。

一方、**実際に応募してくる看護師・セラピスト本人がいるのは Instagram です。**
採用が目的なら、最終的に Instagram は外せません。

Threads は Instagram と客層が近く、しかもテキストなので **X の素材をほぼそのまま使えます。**
語尾をやわらげるだけなので、追加の手間は1投稿あたり3分です。

---

## 2. 段階的に足してください【重要】

**9/1に4媒体同時スタートは、やめたほうがいいです。**

理由は単純で、**連載が止まるからです。**
この企画でいちばん大事なのは「週1で出し続けること」で、それ以外は全部その次です。
初週から画像制作まで抱えると、3週目で止まります。

| 時期 | 媒体 | 理由 |
| --- | --- | --- |
| **9月** | note ＋ X ＋ Threads | Threads は X の素材の語尾を変えるだけ。追加コストがほぼない |
| **10月** | ＋ Instagram | 9月のうちにカルーセルのテンプレを1つ作っておく |
| **11月〜** | 反応を見て、伸びている媒体に寄せる | 4媒体を等しく回し続ける必要はありません |

書くことが習慣になってから、配信先を増やしてください。順番が逆になると、両方できなくなります。

---

## 3. Instagram は「図鑑」と相性がいい

**「人事の失敗図鑑」という名前は、カルーセルに非常によく合います。**
1つの失敗を、図鑑の1項目として見せられるからです。しかもロゴがあるので、統一感を出しやすい。

### カルーセルの型（9〜10枚）

| 枚 | 内容 |
| --- | --- |
| 1 | **表紙**。失敗のタイトル＋ロゴ＋「元管理者Ns」 |
| 2〜3 | 場面。コラムの冒頭をそのまま |
| 4〜6 | 状況と、当時の自分の考え |
| 7〜8 | **turn**。ここが保存される |
| 9 | 「まだ解けていない」一行 |
| 10 | 署名＋「毎週火曜」＋プロフィール誘導 |

**1枚に文字を詰め込まないこと。** 1枚＝1〜3行が上限です。スマホで読めなければ意味がありません。

Canva でテンプレを1つ作れば、以降は文字の差し替えだけで**1本15分**です。

## 4. Buffer の実務

### 順番

1. **note を手動で公開**（Buffer は note に対応していません）
2. 公開された URL をコピー
3. Buffer で X・Threads・Instagram を予約

### 注意点

- **Instagram はビジネスアカウントかクリエイターアカウントが必要です。** 個人アカウントのままだと Buffer から自動投稿できません
- **Instagram のキャプションに書いたリンクは押せません。** 「プロフィールのリンクから読めます」と書いて、プロフィールにマガジンの URL を置いてください
- **Threads も、外部リンクが入るとリーチが落ちる傾向があります。** 「1投稿目にリンクを置かない」という原則は、ここでも同じです
- **予約時刻をずらしてください。** 同じ時刻に3媒体へ流すと、複数フォローしている人に同じ話が3回届きます

> Buffer の対応媒体・料金プラン・機能は変わります。**契約前に公式サイトで最新の仕様を確認してください。**
> 特に Instagram のカルーセル投稿とストーリーズは、プランによって扱いが変わることがあります。

## 5. やってはいけないこと

### 同じ文章を、3媒体に丸ごと流す

**これが一番多い失敗です。** そして、どこも伸びません。

読者が違うので、同じ素材から違う形を作ってください。
手間は増えますが、**コラム本体さえ書けていれば、変換は各15分**です。書くことに比べれば軽い作業です。

### アカウントの純度を崩す

X の運用で決めたルール（`swipe-file.md`）は、Instagram でも Threads でも同じです。
**フォロワーが求めていない投稿を混ぜると、アカウントの定義がぼやけます。**

日常投稿をしたくなったら、別アカウントでやってください。

### 媒体を増やしたあとに、記事を落とす

配信先が増えるほど、記事を落としたときのダメージが大きくなります。
**2本先まで書き溜まっていない週は、媒体を増やさないでください。**

---

## 6. 週の作業（テンプレ）

| 曜日 | やること | 目安 |
| --- | --- | --- |
| 金 | note 原稿を仕上げて、代表に渡す | 60分 |
| 月 | 代表コメントを反映。Instagram のカルーセル画像を作る | 30分 |
| **火 7:00** | **note を手動公開** → Buffer で予約を入れる | 15分 |
| 火 | X 朝／Threads 昼／X 夕（リンク）／Instagram 夜 | 予約済み |
| 水 | 反応を保存する。次の回の素材になる | 10分 |

**合計で週2時間弱。** これ以上重くすると続きません。
