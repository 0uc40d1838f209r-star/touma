# 運用手順書 ── note を軸に発信する

**note が本体。X・Threads・Instagram は入口です。**
入口で興味を持った人が note に来て、そこで会社を判断して、応募する。この流れを毎週まわします。

---

## 0. 全体像

```
        原案（drafts/）
             │
             ▼
   ┌──── note に記事を公開 ────┐   ← ここが本体。ここだけは毎回手作業
   │                          │
   ▼          ▼          ▼    ▼
  X        Threads   Instagram  採用ページ
（抜粋2投稿）（1投稿）（カルーセル）
   └──── 全部 note に戻す ────┘
```

**入口の投稿だけを読んで終わる人は、応募しません。** 入口の役割は「note に来てもらうこと」だけです。
だから、どの媒体でも**話を最後まで書き切らない**でください。

---

## 1. 一度だけやる準備

> **note を触るのが初めてなら、`note-setup.md` を先に見てください。**
> アカウント作成から自己紹介記事の公開、マガジン作成、第0回の公開までを、画面の流れに沿って書いています。
> ここはその要約です。

### 1-1. note のアカウント

- 表示名は **元管理者Ns**
- プロフィール文（**140字まで**）は `profile-texts.md` から。X・Instagram・Threads 用も同じファイルにあります

- プロフィール画像はロゴ（`assets/logo.jpg`）
- **クリエイターページのリンクに、採用ページか応募フォームを設定する**

### 1-2. 自己紹介記事を出して、プロフィールに固定する

**連載の1本目より先に、自己紹介記事を出します。**

- 原案：`drafts/profile.md`
- 第0回（連載の宣言）とは役割が違います。こちらは「私は誰か」の常設ページです
- **マガジンには入れません。** プロフィールに固定表示して、ずっと置いておくもの
- ハッシュタグに `#自己紹介` を入れる

投稿を読んだ人が「この人は何者か」を確かめに来る場所になります。

### 1-3. マガジンを作る

連載は必ずマガジンにまとめてください。**1本ずつバラバラだと、2本目以降が読まれません。**

- マガジン名：**人事の失敗図鑑**
- マガジンの画像はロゴ（`assets/logo.jpg`）
- 説明文はこれをそのままコピー：

```
訪問看護ステーションで人事を見ている元管理者Ns（三井斗真）が、自分がやってきた人事の失敗を書いていきます。

うまくいった話は書きません。あれはどこの会社の採用ページにも載っているので。

24歳のとき、駅のホームで、電話一本で管理者になりました。
訪問看護も、管理者も、はじめてでした。

そこから、今、人を採る側になるまで。失敗は今も続いています。
```

### 1-4. 計測の仕込み【最重要・公開前に必ず】

**この2つがないと、連載が採用に効いているのか永久に分かりません。**

1. 応募フォームに「当社を知ったきっかけ」の自由記述欄を追加する
2. 初回面談の冒頭質問に「note は読みましたか。どの回ですか」を定型で入れる

ダッシュボードを作るより先に、この2つです。

### 1-5. 各SNSのプロフィール

投稿を読んだ人は、必ずプロフィールを見に来ます。**ここが整っていないとフォローされません。**

| 媒体 | やること |
| --- | --- |
| X | 肩書きに「訪問看護ステーションの人事」。固定ポストにマガジンのリンク |
| Threads | X と同じ内容で揃える |
| Instagram | **ビジネスまたはクリエイターアカウントに切り替える**（個人アカウントだと Buffer から投稿できません）。プロフィールのリンクにマガジンの URL |

## 2. 記事を作る（毎回）

### 2-1. 貼り付け用のテキストを作る

**note のエディタは Markdown をそのまま解釈しません。**
原案の `**太字**` や `## 見出し` をそのまま貼ると、記号が文字として残ります。

なので、貼り付け用のテキストを先に作ります。

```bash
python3 note/make_note_text.py note/drafts/00-hajimeni.md
```

`note/note-paste/` に2つのファイルができます。

- `00-hajimeni.txt` ── **記号を抜いた本文。そのまま貼れます**
- `00-hajimeni-整形メモ.txt` ── 貼ったあとに手で直す箇所のリスト（何行目を見出しにするか、など）

### 2-2. note に貼って、整形する

1. note で「テキスト」の新規投稿を開く
2. **タイトル欄**に、整形メモの1行目のタイトルを入れる
3. 本文に `.txt` を全部コピペする
4. 整形メモを見ながら、上から順に直す
   - **大見出し** ── その行にカーソルを置いて、ツールバーの見出しボタン
   - **区切り線** ── その位置でツールバーの区切り線ボタン
   - **太字** ── その文を選択して太字ボタン（`Ctrl+B` / `⌘B`）
   - **引用** ── その行を選択して引用ボタン

整形メモは上から順に並べてあるので、**メモの順にやれば迷いません。** 慣れれば10分です。

### 2-3. 見出し画像を入れる

```bash
python3 note/instagram/make_carousel.py note/instagram/slides/00.txt
```

`note/instagram/out/00/note-header.png`（1280×670）ができます。これを記事の見出し画像に設定してください。

> Instagram のカルーセル画像（1080×1350）とは**サイズが違います。**
> note に縦長画像を使うと、上下が切れて文字が読めなくなります。必ず `note-header.png` のほうを使ってください。

### 2-4. 公開設定

| 項目 | 設定 |
| --- | --- |
| マガジン | **人事の失敗図鑑** に追加する（忘れやすい。ここが連載の生命線です） |
| ハッシュタグ | `#訪問看護` `#看護師` `#人事` `#採用` の4つ程度 |
| 価格 | 無料 |
| 予約投稿 | **note の有料プランが必要な場合があります。** 使えないなら火曜の朝に手動で公開してください |

## 3. 連結する（配信）

**必ず note を先に公開してから**、各媒体に流します。リンク先が無いと1投稿目が無駄になります。

### 手順

1. **note を公開する**（手動）
2. **公開された URL をコピーする**
3. Buffer を開いて、下の4つを予約する

| 時刻 | 媒体 | 内容 | リンク |
| --- | --- | --- | --- |
| 朝 7:30 | X 投稿1 | コラムの冒頭（場面） | **貼らない** |
| 昼 12:00 | Threads | 1投稿・やわらかい口調 | **貼らない** |
| 夕 18:00 | X 投稿2 | turn ＋ リンク | 貼る |
| 夜 20:00 | Instagram | カルーセル ＋ キャプション | プロフィール誘導 |

原稿は全部 `distribution.md` にあります。

### なぜリンクを1投稿目に貼らないのか

X も Threads も、**外部リンクが入るとリーチが落ちる傾向**があります。
1投稿目はリンクなしで広く届かせて、夕方の2投稿目で回収する。この形が一番読まれます。

### Buffer で気をつけること

- **note は Buffer に対応していません。** note の公開だけは毎回手作業です
- **Instagram のキャプションに書いたリンクは押せません。** 「プロフィールのリンクから読めます」と書いてください
- **予約時刻をずらしてください。** 同時刻に3媒体へ流すと、複数フォローしている人に同じ話が3回届きます

> Buffer の対応媒体・料金プラン・機能は変わります。**契約前に公式サイトで最新の仕様を確認してください。**

## 4. 毎週のルーティン

| 曜日 | やること | 目安 |
| --- | --- | --- |
| **金** | 次回の原案を仕上げて、代表に渡す | 60分 |
| **月** | 代表コメントを反映。`make_note_text.py` と `make_carousel.py` を実行 | 20分 |
| **火 7:00** | note に貼って整形 → 公開 → URL をコピー → Buffer で4つ予約 | 30分 |
| **火（自動）** | X 朝／Threads 昼／X 夕／Instagram 夜 | 0分 |
| **水** | 反応を保存する。次の回の素材になる | 10分 |

**合計で週2時間。** これ以上重くすると続きません。

### 落としそうな週の優先順位

1. **note** ── これだけは落とさない
2. **X** ── note があるなら、2投稿は5分で出せる
3. Threads
4. **Instagram** ── 落としてよい。画像は後追いで出しても誰も困りません

## 5. 数字の見方

note の PV とフォロワーは**先行指標にすぎません。** 目的は採用なので、3層で見ます。

| 層 | 見るもの | 何が分かるか |
| --- | --- | --- |
| 先行 | 読了率、スキ、X の保存数 | 記事の質 |
| 中間 | 記事から採用ページ・面談申込への遷移 | 導線が効いているか |
| **本命** | **応募のうち note 経由の比率／初回面談での言及率／内定承諾率／6ヶ月定着率** | **目的そのもの** |

**毎日 PV を見るのはやめてください。** 週1で十分です。
数字を追い始めると、次回のタイトルを煽り型に変えたくなります。それをやった時点で、この連載の価値は消えます。
